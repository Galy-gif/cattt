# 轨道 3 · revision-2

## 猫作为尺度基准

新增 `05-cat-scale-reference.png`：从 canonical 已有透明图机械填黑，按120px可见主体高度放在每行左侧，与同一暂定尺度的25物件脚底对齐。物件没有再次生成、也未在各行单独放大。凳高160px、碗宽80px、单叶24px，小铃24px是可读性例外；这是一组当前App像素比例，尚不是已确认的真实厘米。今后物件按此猫基准比较，任何改尺度应更新整张基准图。脚本为 `work/props-cat-scale.swift`。

三批均实际重新调用内置 imagegen，以各自上一版为图参考定点编辑，保留物件设计与顺序。旧版未覆盖。三张根目录原图每张 1254 × 1254，各 16 件，清单共 48/48 齐全，无明显重叠。

## 已改善

- 自然批珊瑚色只保留小花与单蘑菇；蘑菇簇改棕色。蒲公英改奶油色种子头，消除了原先大块黄花。
- 小铃、单叶、碗等已在新生成原图中缩小；三批轮廓比上一版更轻，内部纹理有所收敛。
- 物件设计基本保留，木凳、藤篮、布料花纹等有明确连续性。

## 新增非生成尺度验收版

原始生成仍没有执行精确尺度，故另用确定性裁切、边界连通底色抠除、等比缩放及拼接制作 `normalized/` 三批网格。没有重新绘制物件或对物件调色。采用提示词中明示的暂定 4px/cm 尺寸表（不是已定稿的游戏世界规格）：凳高 160px、碗宽 80px、单叶长 24px。根复核后，小铃由 12px 调为最低可读高 24px，明确作为艺术尺度例外。网格外部底色统一为 `#EFE6D2`。

`04-25-props-consistency.png` 从标准化三批中交错选 25 件；包含铃铛与单叶，使用同一尺寸表（铃铛 24px 例外），不再单独撑满格子。根复核后收紧格间空白，保持每个物件的实际像素尺寸，改为紧凑单屏。最下排第 3 件是刻意选择的自然批第 9 件「单叶」，不是第 8 件「落叶堆」；相比上一轮换入单叶，是为核查此前最明显的小物件尺度问题，并非编号错位。

复现命令：

```sh

```

## 仍未完全通过

1. 原始生成三批仍存在填格倾向，没有达到同一世界尺度；标准化版修正的是屏幕尺寸，无法反推所有物件内部透视比例。
2. 绿仍偏橄榄，木色偏暖；小花花心和纸袋有暖黄倾向，不能宣称严格限于色板。背景原图仍有轻微纹理与暖度差。
3. 标准化版抠除的是边界连通底色。封闭的篮把／绳圈等内部空隙可能保留原底，细边存在浅色晕；并非生产级透明资产。
4. 缩小后线宽也缩小，小铃已提升到 24px 艺术尺度，但仍需 App 实机验证；跨批纹理基本协调，但织物仍比植物密。尚未达到最终统一线宽与小尺寸可读性。
