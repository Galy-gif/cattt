# 聊天页 C3：写实猫与透明玻璃，两种背景

来源：[聊天页讨论稿](../../../docs/specs/聊天页视觉重设计-讨论稿-2026-09-16.md) 的 C3 更新。

## 用户本轮要求

- 猫用真实猫的形象，替代线条猫；保留上一轮圆窗露头与扒窗前爪。
- 对话框、打字框采用透明玻璃质感；背景清透／渐变都试一下。
- 消息用足横向可用宽度，到边缘再自然换行，不提前手动断句。

## 参考用途

- C2 页面为编辑目标，保留中文聊天结构、圆窗与输入框内小型珊瑚发送键、蘑菇屋柔光。
- `IMG_9057.jpg` 只借消息宽度／自动换行和透明玻璃层次；不借人像、英文、电话、反馈按钮、停止生成、水印、卡片外框或高饱和紫青色。
- 本轮为生成的写实橘猫头像风格示意，不是真实拍摄照片，不替代团子世界层的身份基准；连续头像动作未制作。

## 两张独立整页

1. C3a 清透灰白：浅灰白背景，轻微弥散光与模糊空间层次，透明玻璃气泡／输入框。
2. C3b 淡色渐变：以 C3a 为母版，只改背景为近白的浅冰蓝、珍珠灰和微暖光的低饱和渐变；允许玻璃随底色透出变化。猫、文字、排布、框形与发送键尽量一致，报告实际生成漂移，不要求每像素相同。

沿用五条对话；“嗯。那就先不用讲道理。”取消显式换行。为展示长回复到边缘换行，最后一条方向稿示意增加续句：“桂花是真的开了吗，我没出去过。你走近的时候，闻到香味了吗？”这仅为排版示意，不写入真实聊天历史或代码。

参考390pt屏宽，左右16pt；猫头像约40–44pt，间隔约8pt；猫气泡从头像右侧延伸到右边距，最大约306pt，文本左右内边距约12pt。短消息仍贴合文字，长消息用足上限再折行；字号不因内容长度缩小。这些是方向图提示，不是最终令牌。

## 收图

清点两张→独立SHA比历史与批内重复→记录原生RGB／RGBA和尺寸→采样背景RGB、颜色差异与珊瑚占比→人眼核对真实猫／爪位、玻璃透底层次、消息自然折行与两底差别。

工具原生比例约2.0–2.3，不拉伸。玻璃质感必须人眼判断，静态RGB图没有真实透射率参数，不能凭RGB／Alpha宣布“透明度已验收”。交付在 `outputs/chat-ui-v3-delivery/`，检查在 `outputs/chat-ui-v3-review/`；最终背景待用户选型，App 未改。
