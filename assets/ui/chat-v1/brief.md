# 聊天页方向图 v1

来源：[聊天页讨论稿](../../../docs/specs/聊天页视觉重设计-讨论稿-2026-09-16.md)。用户授权一张页面图，头像采用猫耳／胡须线条符号。

## 交付

- C1：一张独立完整 iOS 聊天页；目标长宽比约 19.5:9，目标 1024×2218；记录工具实际尺寸，允许接近该比例的原生结果，不拉伸纠正。
- 内置 imagegen 生成。白底、现有珊瑚强调；保留截图五条对话与基础导航／输入结构；气泡、头像符号与背景重新设计。
- 不传团子角色图：本轮图标是通用猫符号，不是角色肖像。附件只借聊天结构和对话内容，不借原灰绿颜色和全身头像。
- 不出拼图、设备样机框或标注；方向图不是 App 整屏资源。
- 交付在 `outputs/chat-ui-v1-delivery/`，清单记录源路径、实际提示词、SHA 与真实状态；证据在 `outputs/chat-ui-v1-review/`。

## 收图顺序与判据

先清点、哈希、格式、量内容，再人眼。已有截图 762×1620、长宽比2.126可作为同类比例参照；原蓝绿底不满足新的白底目标，这正是本轮要改变的项。新目标来自用户诉求，不作为旧图合格门槛。

| 量什么 | 目标或报告方式 | 理由 |
|---|---|---|
| 数量 | C1 单屏一张 | 用户只要求一张 |
| SHA | 新图不能与既有仓库图完全相同 | 防止旧图顶替；哈希不等不代表视觉质量通过 |
| 格式 | RGB／RGBA PNG、竖图；长宽比约2.0–2.3，报告实际像素 | 接近当前手机屏幕；目标尺寸只作生成提示，禁止为过关拉伸 |
| 白底 | 报告采样空白区域的RGB／L*，以及全图近白低彩度像素占比；以白色占主导为目标 | 用户明确白色为主；不套用旧页底暗部阈值 |
| 红色 | 报告珊瑚色系强色像素占比与分布，主强色来自发送键，小猫符号保持细线 | 用户要求少量现有发送键红色；极浅珊瑚气泡与柔光单独描述 |
| 结构／文字 | 人眼核对五条消息顺序、左右角色、完整顶部和输入区 | 数量和颜色统计不能证明中文与布局正确 |
| 猫符号／场景 | 人眼检查耳朵和胡须是否清晰、符号是否一致，蘑菇屋轮廓是否可辨且不干扰文字 | 不冒充角色身份校准或实际App可用性验收 |

母版交付后先让用户看；不因未选型自动派生多版，不改 App。
