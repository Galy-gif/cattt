# 团子图标层剪影探索

使用内置 imagegen，两次调用都以 canonical 正面图作为唯一参考。第一版尾巴偏 C 钩，未采用；第二版增加反向弯曲，作为本轮候选。实际提示词见 [[prompts]]。

## 交付

- `icon-master-generated-v2.png`：第二次生成的原始位图，保留不动。
- `icon-24px.png`、`icon-48px.png`、`icon-180px.png`：对应真实 24×24、48×48、180×180 像素。
- `icon-24-48-180-true-size.png`：348×224 像素对照图，左至右为 24、48、180；三个原尺寸直接放置，没有放大。请以 100% 查看。
- `export.swift`：可重复运行的尺寸与单色导出脚本。

## 核查

实际尺寸已用 sips 核验。24px 下仍能分出两耳与独立尾巴，尾部和身体之间留有可见空隙。体型保持大头、宽臀、短脚；无脸、无纹、无毛束。24px 的 S 尾上端弯曲较弱，48px 与180px 更清晰，因此本轮可用于评审方向，尚不能断言用户只靠该小图即可认出团子。最终矢量化时应优先验证 24px 下的耳角差异和 S 尾反向弯曲。

生成原图仍带轻微色彩变化，导出时按颜色差提取轮廓，统一为蜂蜜橙 #E3A05C、奶油底 #EFE6D2；只有边缘保留缩小抗锯齿。没有机械改画轮廓、拉宽身体或重画尾巴。

图标是位图探索稿，**不是最终矢量资产**。本轮按24px识别优先指导模型，但工具输出的是高分辨率母图，随后真实缩小核查；不能将其表述为模型直接从24px像素网格绘制。
