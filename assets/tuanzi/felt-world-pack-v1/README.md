## 统一后的美术规则

- 团子保持原蜡笔插画为主，只增加克制的短纤维毛毡表面和柔软轮廓毛边。
- 小院与九姿态道具使用层叠剪裁毛毡、浅层结构和少量缝线细节。
- 团子仍为厚圆体型、短腿、小圆爪、橘色虎斑；不增加奶白胸口或肚皮。
- 嘴巴保持一笔很小、比毛色略深的暖棕色，正常尺寸下若隐若现。
- 磨爪动作继续使用 cat-only 角色表；树干只出现在定位参考和场景层。
- 困倦沿用身体锁定的 v2；奔跑沿用无接触影、无奶白肚皮的 v2；蜷睡呼吸沿用 2–3% 幅度的 v2。
