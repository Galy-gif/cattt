# 毛毡动作帧 · 切帧产物 · 2026-09-09

由 `assets/tools/slice_sheet.py` 从 `../actions/` 八张横条机械生成，可复跑：

```
cd assets/tools
python3 slice_sheet.py --sheet-dir ../tuanzi/felt-world-pack-v1/actions --out ../tuanzi/felt-world-pack-v1/frames
python3 fix_walk_tail.py --frames ../tuanzi/felt-world-pack-v1/frames/walk --donor 5 --target 6   # 切帧后必须跑，见下
python3 gen_preview.py --frames ../tuanzi/felt-world-pack-v1/frames --bg ../scenes/tuanzi-courtyard-v1/02-tuanzi-courtyard-background-felt-selected.png --out /tmp/preview.html
```

## 内容

- `<action>/<action>-r-01..06.png`：源分辨率 RGBA，同一动作六帧同画布、脚底同一行、按动作锚点水平对齐。`r` = 朝右，向左在代码里镜像。
- 水平锚点（manifest 的 `anchor`）：`feet` 脚掌带质心（困倦、眨眼、磨爪、蜷睡）／`hindfeet` 后脚（伸懒腰）／`torso` 去腿去尾的躯干（走路、奔跑）／`centroid` 整猫（追尾巴）。
  09-09 晚叠影发现整猫质心会让脚跟着头晃，改成这套。复核方法：六帧 35% 透明度叠在一起看脚有没有重影。
- `manifest.json`：每动作的 fps / loop 起始值、画布、脚底行、逐帧 bbox / 高度 / 面积 / 主色 H,S / 杂点，以及 `scale`（相对走路帧，按 sqrt 面积对齐）。

## 去底方法

四边 12px 边框中位色作底色（八张实测 `#C4D7C2`–`#C6D8C3`，P99 偏差 3.0）。从裁片外框泛洪「像底色」（RGB 距离 < 34）的连通区为外部；外部里贴着主体的像素按距离 10→34 渐变 alpha 并反混色，保留毛毡毛边、不留绿晕；离主体 8px 外的半透明杂点清零。

## 走路第 6 帧尾巴（2026-09-09 修）

横条里 1、2、5 帧尾巴左倾，3、4、6 帧竖直，循环 6→1 会跳。`fix_walk_tail.py` 用形态学开运算把尾巴从身体分出来，
把第 5 帧的尾巴按关节位置平移 (6, −19) 移植到第 6 帧，序列变成 倾、倾、直、直、倾、倾。
原第 6 帧在 `walk/_orig/`。**`slice_sheet.py` 会把第 6 帧重新切回原样，重跑切帧后要再跑一次这个脚本。**
