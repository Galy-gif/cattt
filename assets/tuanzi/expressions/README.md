## 本轮沉淀的规则

1. 单张全幅出图，不出六宫格 —— 六宫格挤压是头身比缩水的真正原因，不是提示词问题
2. 已通过的图不再重掷 —— v3 重掷 05 直接毁掉了全套最好的一张
3. 情绪必须做进身体，不能只做在脸上；用剪影测试验收
4. 亲昵类表情必须有画面内可见的对象，"画外某物"模型锚定不了
5. 保留「无眼神光」—— 半眯眼形自己能撑住表达，不需要高光
6. 碎毛边缘是比尾巴更强的识别锚点（六张剪影里唯一始终一致的特征）
7. 委托出图时必须要求：生成失败或沿用旧图要明确报告，禁止静默交付旧文件
