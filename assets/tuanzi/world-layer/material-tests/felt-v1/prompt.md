# 团子轻毛毡材质试样 v1

## 目标

验证现有蜡笔团子进入「柔软毛毡拼贴小院」时的材质衔接。只做单只标准站姿试样，不覆盖九姿态或任何动作帧。

## 参考

- 身份、比例、五官与花纹：`assets/tuanzi/world-layer/01-nine-poses.png`
- 环境材质：`assets/scenes/tuanzi-courtyard-v1/02-tuanzi-courtyard-background-felt-selected.png`

## 最终提示词要点

- 保留大圆头、豆形身体、超短腿、小圆爪、点状眼睛、三道额纹、背纹与环尾。
- 身体保持通体橘色，不增加奶白胸口或肚皮。
- 嘴巴是一笔很小、比毛色略深的暖棕色，仍保持若隐若现。
- 保留暖棕蜡笔轮廓，仅在橘色填充和轮廓边缘增加轻微短纤维毛毡感。
- 材质比例约为 20% 毛毡、80% 原蜡笔插画；不做立体毛绒玩具、缝线或布贴。
- 使用干净浅奶油色展示背景；不伪装成透明资产。
