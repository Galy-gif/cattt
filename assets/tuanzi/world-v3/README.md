# 团子世界 v3 动作素材

2026-09-10，内置 imagegen 生成，沿用磨爪参考的橘猫身份、蜡笔主体与轻毛毡触感。

- `jump-atlas.png`：4×3 跳起、抓沿、攀入、出窝、落地、趴栏关键姿态；生成器返回 RGB 棋盘背景，非原生 Alpha。
- `flower-source.png`：独立毛毡雏菊，生成源图使用洋红底，打包为 `world-v3-flower.png`；不从栅栏挖走背景块。
- `interaction-atlas.png`：4×3 转身、磨爪、玩花关键姿态；RGB 洋红背景。
- `assets/tools/package_world_v3.swift`：确定性工程导入，逐格分离猫轮廓、移除色键及邻格溢出的孤立碎片、统一尺度、脚底或腹部支撑锚点，再打包为真正 RGBA imageset。无新绘制像素。保留源图。
- 跳起／攀入／离开／落地分别计时；趴栏有独立腹部支撑点，不能按脚底对齐。
- 生成的磨爪第八格朝向错误，未采用；使用第五至第七格的接近与磨爪变化。

实际提示词见 `prompts.md`。这些图不是单靠帧数即可验收，需以 App 内接触、遮挡与衔接为准。
