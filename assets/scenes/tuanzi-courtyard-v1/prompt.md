# 团子小院背景 v1 — 生成说明

## 目标

为团子世界层制作一张可复用的横向完整小院背景。背景不烘焙猫，供走路、奔跑、伸懒腰、磨爪、玩尾巴、困倦、眨眼与睡眠等动作层叠加。

## 参考层级

1. 画风与尺度正本：`assets/tuanzi/world-layer/01-nine-poses.png`
2. 空间骨架：`assets/scenes/六个场景-绘本风-v2-hue+15/07-庭院全景图.png`
3. 道具与留白参考：`assets/scenes/5a-5b/scene-5ab/5b-layout-check.png`

## 生成要求

- 横向连续庭院，约 2.1:1；不是拼贴、分镜或九宫格。
- 左侧蘑菇屋与休息区，中部大树、吊篮、磨爪区与草丛，右侧池塘、矮栅栏和通往远山的小路。
- 使用团子九姿态一致的手绘蜡笔/彩铅质感：暖棕色不规整描边、圆润简化造型、低饱和柔和配色。
- 前景和各区域之间保留可供团子行走、奔跑和停留的连续空地。
- 背景层中不得出现猫、人物、角色投影、UI、文字、标注、网格、水印或签名。
