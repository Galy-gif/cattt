# 小院全景 v1 · 复核 · 2026-09-08

复核方 Claude。量法与脚本同 `assets/tuanzi/world-layer/action-sheets-v1/QA-第一轮复核.md`。

## 结论

方向对，**这一版不能进产线**。两个硬伤：分辨率不够一屏，规则 1 在左三分之二不过。

## 1. 分辨率：差 3 倍

| | 值 |
|---|---|
| 交付 | 1821 × 864（2.108:1） |
| 竖屏一屏 @3x | 1206 × 2622（402 × 874 pt） |
| 从全景裁一屏的竖条 | 864 × 0.46 = **397 × 864** |
| 需要的放大倍数 | **3.03×** |

`exports-ui/README.md` 的产线约束是「不应把旧图插值扩尺寸」。

**要的尺寸：`5528 × 2622`**（比例不变）。退一步 @2x 是 `3685 × 1748`，但 3x 屏上会看出软。
一次出不了这么大就横向分 2–3 块、每块满高、留 10% 重叠后拼。

按这个尺寸，全景 = **4.6 个屏宽**，够走。

## 2. 规则 1：左三分之二不过

团子实测色 H 29.7°、S 0.710（走路横条六帧均值）。沿行走带（y 620–820）逐 60px 列量地面：

| 列区间 | 地面 H | 色相角距 | 判定 |
|---|---:|---:|---|
| 0–960 | 60.7–77.4° | **31.0–47.7°** | ✗ 全段不过 |
| 960–1620 | 84.7–150.4° | 55.0–120.7° | 过 |
| 1620–1821 | 63.8–75.2° | **34.1–45.5°** | ✗ 不过 |

31 个列区间里 **20 个不过**。要求是角距 ≥55°。

S 差全段 0.24–0.46，**这一项处处达标**，问题纯粹在色相角。

**对照：已通过的 `六个场景-绘本风-v2-hue+15/01-蘑菇屋`**，同一量法地面 103.9–107.6°、角距 74.2–77.9°，过线。
差别在于六张走过 +15° 色相旋转，而这张全景是新生成的、没走那一步，而且底子比 v1 还黄
（v1 六张是 70–83°，这张 60–75°）。

### 不建议用 hueshift.py 救

要让最差那段（60.7°）过线，需要 **+24°**。而决策-2026-09-08 第 2 条写得很清楚：
+20° 开始丢下午光，+28° 发冷发数码味。+24 落在已经被否掉的区间里。

**建议重出**，生成时直接把地面色相打在 90–105°。

## 3. 提示词里的色板没被执行

`prompt.md` 写的草地是 `#C6D9C4` —— 这个色 H 114.3°、S 0.097。
实测地面 H 60–75°、S 0.35–0.47。色相差 40–54°，饱和差 3–5 倍。

重出时把单色指定换成**可验收的区间**，单个 hex 挡不住生成模型：

- 地面主色相 **90–105°**，饱和 **0.25–0.45**
- 沿整条行走带每 60px 采样，与 H 29.7° 的角距全段 ≥55°

## 4. 规则 3 本轮不判

我的量法（HSL L）在**已经通过的** v2 场景上也只得 4.5%，远低于规则里的 60%，
说明我的量法和当初定规则时用的不是同一个（很可能是 Lab L\*）。

参考值：全景天空平均 L 81.5、L>85 占 0.1%；v2 场景 01 平均 L 82.3、占 4.5%。
两者同一档，全景略暗一点。等量法对齐再判这条。
