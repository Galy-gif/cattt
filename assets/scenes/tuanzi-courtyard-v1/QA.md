# 团子小院背景 v1 — QA

## 结论

可作为完整小院的背景候选 v1，供角色动作层叠加。

## 已核对

- [x] 画面为单张连续横向空间，不是场景拼贴。
- [x] 蘑菇屋、大树、吊篮、磨爪区、草丛、池塘、栅栏和外侧路径均存在。
- [x] 背景内没有猫、人物、UI、文字、标注和角色接触影。
- [x] 前景中央留有较大的连续行走区，动作切换不会被道具遮断。
- [x] 主色为浅青、鼠尾草绿、奶油白、陶土红和暖棕，橘猫叠加后仍有清楚色差。
- [x] 输出尺寸为 1821 × 864 PNG，适合横向全景使用。

## 使用约束

- 团子必须作为独立透明动作层叠加，不要再次生成在背景里。
- 地面接触影由动作层或运行时统一控制；本背景不含角色投影。
- 树干磨爪动作使用猫-only 帧；树干位置与尺度以本背景的大树为准。
- 如需竖屏主页，请从本全景做视口裁切/平移，不要重新改变各区域的相对位置。
