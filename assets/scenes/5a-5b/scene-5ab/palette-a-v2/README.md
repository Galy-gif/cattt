## 实测

明度统一采用 sRGB D65 的 CIELAB L*（0–100）；天空另报编码RGB的加权Y8（0–255）。所有区域是固定矩形中位值，不是模型声称的颜色，也不是语义分割全区域平均值。

| 合成后 L*<60 占比 | 16.04% | 若要求作用于合成图，则超上限 |
| 草地远→中→近 L* | 81.50→72.48→67.47 | 单调变暗通过 |

## 规范尚需统一的数值

1. 表内地面中/近色值的蓝通道本身只有173/153，与「地面主体≥185」不能同时严格应用于每一层。远景锚点仍应达到#C6D9C4，本稿还没达到。
2. 天空#EFE6D2的编码Y8约230，而硬指标≥235；文档明度列0–100与天空0–255混用。
3. 表内相邻层标称明度差多为6–9，与所有相邻层ΔL≥12也有冲突。实际色值转换得到的CIELAB值又不同于表内标称值。

这轮按扩展色板方向修改，没有擅自重写源文档或把冲突视作已经解决。继续精修应先固定明度单位与色板/阈值优先级，再按区域锁色；本稿不升级为生产封版。
