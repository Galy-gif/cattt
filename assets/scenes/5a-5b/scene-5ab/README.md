## 验收

1. 猫：前景中下部篮中团子，颜色最醒目；最后合成到最上层，后续物件不会挡住它。人工原尺寸检查可直接定位，未擅自加重猫的轮廓或改脸。
2. 密度：30个物件集中在屋前到前景的一簇，含树旁悬挂件。外接范围占全画面53.96%，接近约55%目标；这是物件簇布局范围，非物件实心像素覆盖率（后者约16.70%）。上方天空、左下池塘和底部留空。
3. 色彩：采用HSV色相<30°、饱和度>65/255、亮度>100/255的较宽红橙色族统计，面积2.79%，包含部分暖木色；不是仅数精确#D8705C像素。图中颜色有彩铅纹理偏差，不能把数值当作逐像素严格色板认证。
4. 安全区：顶148px、底222px未新增任何图层/阴影，已与背景板逐像素比较。
5. 接触阴影：地面物件统一向右下偏移2/3px，低不透明度、柔化；悬挂灯与鸟屋未加落地阴影，避免悬挂物被错误钉到地面。
