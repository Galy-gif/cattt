# 日记完整交互流与手绘图标系统

## 本轮结论

- 背景固定为均匀暖白 `#F6F5F0`，内容使用白色 iOS inset grouped 表面，不添加花草边框、渐变、纹理或大阴影。
- 页面主标题从「今天这一页」改为「今天」。
- 搜索、日历、日期切换、当天详情、由留言进入聊天、月份归档全部补齐。
- 可爱感来自图标轮廓本身，不用 emoji、3D 材质或假手绘纸纹。

## 交互入口

| 入口 | 打开状态 | 目的 |
| --- | --- | --- |
| 搜索图标 | `02-search-diary.png` | 搜索日记正文、原始语音转写和日期 |
| 日历图标 | `03-calendar-month.png` | 完整月历，查看有记录和团子来过的日期 |
| `9月2日 星期三` | `04-date-switcher-sheet.png` | 快速切换今天和最近日期，完整月历仍由日历入口承担 |
| `今天` | `05-today-detail.png` | 查看完整当天时间线与可编辑「今日小记」 |
| `聊聊` | `06-chat-from-diary.png` | 带着原日记片段进入团子专注聊天 |
| `这个月` 或日期卡 | `07-month-archive.png` | 进入只展示有记录日期的纵向月份归档 |

## 团子来过的三态

1. 团子尚未阅读：不显示任何标记。
2. 团子读过但没有评论：只显示一枚小脚印，不显示文字、头像或气泡。
3. 团子有评论：显示团子线画头像、评论正文和「聊聊」入口。

脚印形态固定为四枚略不等大的趾豆和一个柔软肉垫，蜂蜜橙线稿，可带极浅平涂。禁止心形肉垫、发光、立体高光和 emoji 表达。

## 图标约束

- 以 24pt 网格为基础，约 1.9pt 深松针绿描边。
- 圆角端点、轻微线宽变化、略有手势抖动和有意的不对称。
- 优先清楚轮廓和关键细节，允许一个低透明平涂色，不叠加材质。
- 搜索、日历、箭头、脚印、蘑菇、团子脸、日记本、陪伴、我的、编辑和更多使用同一套线画语法。
- 图标母版见 `08-handdrawn-icon-system.png`。
