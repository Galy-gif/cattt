# 院子天气 · 2026-09-16

方案见 [院子天气-真实与手动切换](specs/院子天气-真实与手动切换-2026-09-16.md)。用户 2026-09-16 批准：「以后换 WeatherKit 可以有，其他按你推荐」。

1. **「我的 → 设置」加「院子的天气」三选一**：跟着真实天气（默认）/ 一直晴天 / 一直下雨。选项持久保存；手动切换时雨三秒起落。
2. **真实天气现在用 Open-Meteo + 系统大致位置（方案 A）。** 公共端点只适合本机非商业开发。
3. **以后仍换 WeatherKit。** A 是当前实现，不取消 09-12 补记第 9 条里换 WeatherKit 的方向；换时只换 `Store/RealWeather.swift`。
4. **取不到真实天气时用上次结果，从没取到过当晴天。** 不再按天随机下雨：09-12 补记第 9 条的"按天随机（B）"就此被取代。
5. 天气仍只分晴、雨；雪、雾本轮不做。
