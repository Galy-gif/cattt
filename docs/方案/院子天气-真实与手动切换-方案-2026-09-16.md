# 院子天气：跟真实天气，也能自己切 · 方案 · 2026-09-16

状态：**已评审（2026-09-16，数据源选 A，WeatherKit 保留为以后的方向），已实施（ef2a328）。** 决策见 [决策-2026-09-16-院子天气](../决策/2026-09-16-院子天气.md)。

用户 2026-09-16 要求：「在 App 里要有选项，可以根据真实天气，也可以自己切换。」起因是院子一直在下雨。

## 一、先说清现状（和"真实天气"的差距）

- **App 里现在没有真实天气。** `Weather.forDay`（`Model/WorldMood.swift`）按日期算伪随机，约五分之一的天下雨，全天不变。这是决策 09-12 补记第 9 条定的第一版（B），原计划链路跑通后换 WeatherKit（A）。
- 真实天气目前只在**后端聊天工具**里（`server/src/runtime/weather.ts`，Open-Meteo），院子不用它。
- 调试脚本 `weather:clear|rain|auto` 只在 DEBUG 包里、只管这一次启动，不是给用户的选项。
- 天气影响的不只是画面：雨声、团子能去哪（下雨躲树窝）、情绪输入、送进聊天的院子事实，全都读同一个 `w`（`AppStore+Conditions.swift` `advanceConditions`）。

所以这件事是两块：**① 给用户一个三选一的设置；② 让"跟真实天气"名副其实。** ① 很小，② 要定数据源。

## 二、设置长什么样

放在「我的 → 设置」，紧挨已有的「下雨时有雨声」，新增一行：

| 左 | 右 |
|---|---|
| 院子的天气 | 当前选项文字 + 系统原生弹出菜单（`Menu`） |

三个选项：**跟着真实天气**（默认）/ **一直晴天** / **一直下雨**。

- 结构层没动：只在现有设置列表里加一行，不新增页面、不动导航。
- 不新开控件：复用现有行的尺寸与字体（和「帮助与关于」右侧文字同一套），弹出用系统 `Menu`，`Components.swift` 里没有分段控件，不为这一行新造。
- 选项存 `UserDefaults`，和 `rainSoundEnabled` 同样的写法；重开 App 保持。
- 手动切换时雨在约 3 秒内起落（现在自然变化是 60 秒，手动切等一分钟会以为没生效）。
- DEBUG 的 `debugWeather` 仍然优先，调试脚本不受影响。
- 措辞：没有打卡类词汇；"一直晴天"比"关闭下雨"更像在说院子而不是开关。

## 三、"跟着真实天气"的数据从哪来（要你选）

| | A. App 直连 Open-Meteo + 大致定位（推荐） | B. WeatherKit | C. Open-Meteo + 手填城市 |
|---|---|---|---|
| 要什么 | 系统「大致位置」权限（使用期间） | 付费开发者账号 + WeatherKit 能力；现在工程是"本地签名"，**模拟器里跑不起来** | 设置里多一个城市输入 |
| 和后端 | 同一家数据，口径一致 | 两家数据可能不一致 | 同 A |
| 限制 | 公共端点只适合非商业开发（和后端同一条限制） | 上架可用 | 同 A |
| 用户负担 | 一次授权弹窗 | 同 A | 要自己输城市 |

**推荐 A**：今天就能在模拟器验，和后端聊天说的天气一致；上架前换供应商时只换取数一处（和当初"只换 `forDay`"的约定一样）。用户确认：A 是现在的实现，以后仍换 WeatherKit。

A 的细节：
- 只要大致位置，不要精确位置；每 30 分钟最多取一次，只在前台取。
- 映射只分两类：有降水（毛毛雨、雨、阵雨、雷雨）→ 下雨；其余 → 晴。雪、雾本轮不做。
- **取不到时（拒绝定位、断网、超时）：用上次取到的结果；从没取到过就当晴天，不再回退到按天随机。** 否则用户选了"真实天气"却看到随机雨，正是这次的问题。
- 拒绝定位时，设置行下方一行小字说明"没有位置，院子先按晴天"，不反复弹窗。

## 四、要改的地方

1. `Model/WorldMood.swift`：加 `WeatherMode { real, clear, rain }`。
2. `Store/AppStore.swift` + `AppStore+Conditions.swift`：存取模式；`advanceConditions` 里按模式取 `w`；手动切换时加快雨的起落。
3. 新增 `Services/RealWeather.swift`（A 方案）：定位 + Open-Meteo 当前天气 + 缓存。`Info.plist` 加定位用途文案。
4. `Features/Me/MeView.swift`：设置里加一行。
5. 世界层逻辑测试加一条：三种模式下 `w` 的取值，以及真实天气取不到时为晴。
6. 增删文件后跑 `ios/generate_project.py`。
