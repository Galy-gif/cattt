前景 ΔE 0.457，位移量取 0 时是 0.454 —— 也就是前景漂移全部来自 8 位量化，**前景没动**。
重新出图做不到这一点：上一轮 U2a–U2d 换底就让前景漂了 ΔE 2.9–3.2。

## 二、量下来发现的问题

### 2.1 `Palette.bg` 不只是页面底，它承担了四种角色

| 用处 | 位置 | 换成渐变之后 |
|---|---|---|
| 整屏页面底 | `App/RootView.swift:14`、`Features/Onboarding/OnboardingView.swift:9` | **要渐变** |
| 卡片／sheet 面 | `Features/Me/MeView.swift:23,27` | 要平色 |
| 图标底座填充 | `MeView.swift:141`、`Features/Diary/DiaryPaperView.swift:54` | 要平色，圆形小色块上放渐变没有意义 |
| 渐变的一个色标 | `MeView.swift:81`、`Features/Shell/Components.swift:401` | 要平色 |
| 调试面板 | `Debug/DebugPanel.swift:106,224,241` | 要平色 |

所以 `bg` 得拆成两支：一支平色给后四种用，一支页面底渐变只给 `RootView` 和 `OnboardingView`。
直接把 `bg` 改成渐变会把图标底座和卡片一起改坏。

### 2.2 整支中性族是从作废的冷薄荷推出来的

`Palette.swift` 顶部写明：薄荷家族的做法是**整体色相转到 130°**，每个令牌的饱和度和相互明度差原样保留。
页面底一旦变成近中性的白，这些绿味的令牌就悬空了 —— 它们当初是为了压在 `#D5E2D7` 上才转绿的。

从方向稿上量出来的值和现行令牌并排：

| 角色 | 方向稿量出 | 现行 `Palette` | 差在哪 |
|---|---|---|---|
| 页面底 | 光晕 `#F4F7FC` → `#F5F5F3` | `bg #D5E2D7` | 已于 `docs/决策/2026-09-12` 第 13 条作废 |
| 说明文字 | `#66696B`（中性灰） | `ink3 #5A705E`（绿） | 色相不同 |
| 进度条未完成 | `#DBDEE4`（冷灰） | `divider #E8EDE9`（绿灰） | 色相不同 |
| 按钮面 | `#C36348` | `accent #C25A3E` | 基本一致，**这支不用动** |
| 按钮文字 | `#FDFFFF`（纯白） | `accentInk #F8EDE6`（暖白） | 方向稿是纯白 |
| 输入框面 | 近白 | `card #FFFFFF` | 一致 |
| 木牌面 | `#EAC38D` | 没有对应令牌（`paper` 是留言纸，不是木牌） | 缺一支 |

**一条要打折扣的**：标题墨量出来是 `#020B08`，比现行 `ink #1F3022` 黑得多。但出图模型画中文正文
本来就倾向于上纯黑，这个值**不能直接当设计意图**。墨色要不要跟着变，建议单独在真机上比，
不要拿这张方向稿的文字颜色定令牌。

## 三、建议怎么改（待评审，未动代码）

分两批，第一批不改观感只改结构，第二批才动颜色。

**第一批 · 拆 `bg`**
1. `Palette.bg` 保留为平色，取光晕的远端 `#F5F5F3`（页面底大部分面积就是它）。
2. 新增页面底渐变（`Palette.pageGlow` 或一个 `PageBackground` 视图），按第一节的光心／半径／两端值实现，
   只在 `RootView`、`OnboardingView` 上用。
3. 其余五处 `Palette.bg` 的用法不变，自动落到新的平色上。

**第二批 · 中性族重新对齐（需要先评审）**
4. `ink2`/`ink3`/`ink4`、`divider`、`rule`、`shadow` 这几支的 130° 绿相位失去依据，
   建议按"保留原有的相互明度差、色相转回中性"重推一次，和第一批一样一次动整支。
5. `accent`/`accentDark` 不动。`paper` 系（留言纸）不动 —— 按 `maomao-ui` 第二节，暖色重音不跟底色走。
6. 木牌缺令牌这件事单独处理，不塞进这批。

**判据**（改完先量再看）：
- 页面底 `L<60` 暗部占比 ≥ 4%（现在 9.45%，改色不应让它掉下来）。
- 卡面与页面底 ΔL ≥ 8 或有 1px 描边；禁内高光、禁双向投影。
- 珊瑚占屏 ≤ 2%，一屏一个主控件。
- 同一套控件压在蓝天／草地／夜空／雨天上 ΔE ≤ 6（这条和页面底无关，但改令牌会碰到）。
