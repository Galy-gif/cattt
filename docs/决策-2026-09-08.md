**2026-09-08 晚，地面色整体压深 8 个亮度点（用户要求）。** 原来的 `#DCE6D6` 放在陪伴主页的草地旁边偏白，
Tab 栏浮在场景上像贴了一块板。做法是量六张场景图底部 18% 的平均色（`#608551`，色相约 95°），
把地面色这一支的色相对齐过去，亮度统一降 8 点，色相和饱和度不动：
`--bg` `#DCE6D6`→`#C7D7BD`、`--rule` `#C3D0BA`→`#AEC0A2`、`--chip` `#CEDCC7`→`#B8CCAE`，
代码侧同批的还有 `pendingCard` `#D6E0CF`→`#C1D0B6`、`pendingSwatch` `#C6D2BF`→`#B1C1A7`、
`meHeaderTop` `#CBDFCA`→`#B2D0B0`、`meHeaderMid` `#E4E7DA`→`#D2D7C1`、`chatBar` 跟 `bg` 走。
**整支一起动**，卡片描边、发丝线、待定稿卡和页底之间原来的明暗差原样保留 —— 只动 `bg` 会让页面上那几条
1px 的线和 chip 直接消失。`ink` 在新底上对比度 9.2:1（原 10.7:1），仍然过 AA。
`ink4` `#8A9683` 在新底上从 2.4:1 掉到 2.2:1，这个令牌只用在计数和占位，本来就没过 AA，记一笔。

夜间模式留给 C「夜与灯」，本版不做。绿底上长文可读性要盯：正文用 `--ink-2` 不用 `--ink-3`，日记详情页字号不低于 15。

## 2. 六场景地面色相：改规则，也改画（我的判断）

**量出来的事实。** 六张绘本风场景（v1）地面色相中位 70–83°，全部落在旧规则「100–120°」之外；暗部 `L<60` 占 39–70%，远超旧规则「8–15%」。但把六张和 5a 背景板并排看，六张明显更好：铅笔纹理、密度、下午光都在，猫也没有陷进去。

**结论：旧规则是给平涂背景板写的，不能直接套在整幅插画上。** 旧规则 1 的目的是「猫在任何位置都能被一眼看见」，那就直接量这个目的，而不是量地面的绝对色相。

**新规则（替换 README 第 0 节）：**

1. 猫与其周围地面的色相角距 ≥ 55°，且猫的饱和度必须明显高于地面（S 差 ≥ 0.2）。
2. 画面必须有三簇色相：暖 10–35°、绿 80–120°、青 180–200°。
3. 暗部规则改为分类型：平涂背景板 `L<60` 占 8–15%；整幅插画不设上限，只要求天空区 `L>85` 占天空面积 60% 以上，保证上半屏透气。

**同时把画往规则方向收了一点。** 对绿色带（色相 50–125°、饱和 > 0.10）整体旋转 +15°，天空、纸色、石径、蘑菇、猫全部不动。试过 +12 / +20 / +28：+28 发冷发数码味，+20 开始丢下午光，+15 刚好压掉芥末黄。结果在 `assets/scenes/六个场景-绘本风-v2-hue+15/`，v1 原样保留。

| 场景 | 地面色相 v1 → v2 | 猫地角距 v1 → v2 |
|---|---|---|
| 01 蘑菇屋 | 71° → 86° | 58° → 73° |
| 02 树屋 | 70° → 85° | — |
| 03 猫窝 | 74° → 89° | — |
| 04 草丛 | 83° → 98° | 48° → 63° |
| 05 池塘 | 99° → 114° | 45° → 59° |
| 06 栅栏上 | 73° → 88° | 45° → 59° |
| 07 全景 | 71° → 86° | — |

处理脚本 `assets/scenes/hueshift.py`，参数可复跑。

## 3. 世界层：第一版直接用六场景整幅插画（我的判断）

- 陪伴主页背景 = `六个场景-绘本风-v2-hue+15/` 中的一张，853×1844 正好是 390×844 的 2.19 倍，铺满即可。世界层的猫已经画在图里，第一版不做猫在场景里走动。

### 1.1 再修订：草地版作废，换冷薄荷（2026-09-08 晚，用户定）

上面那次「压深对齐草地」的结果用户看了实拍后判定不好。真正的问题不在明度，
在**圆角**：`radiusCard` 3pt / `radiusControl` 4pt 是印刷品的语言，压深之后更像一块深色卡纸。

按参考图（dribbble@Anastasia Golovko, Travel app design）重做，完整推导见
`docs/specs/视觉修订-参考travel-app-2026-09-08.md`。三条同时改：

1. **底色** 全部换成中性冷薄荷 `#DEE9E3`（色相 147°），**包括陪伴主页浮在草地上的玻璃层**。
   「UI 是院子的延伸、底色取自场景地面」这条论点**作废** —— 底色的职责只是托住卡片。
   场景层原来的暖纸色面（地点轨、状态条）一并转薄荷，否则同屏冷暖打架。
   团子的留言纸、木牌、爪印保持暖色：那是重音，不是底。
2. **圆角** 两档 → 四档：`radiusSm` 10 / `radiusControl` 12 / `radiusCard` 14 / `radiusLg` 18，长条一律满圆胶囊。
3. **图标** 九档 → 两档：`IconSize.sm` 16 / `md` 20，层级改由容器（`iconSlotSm/Md/Lg` = 28/36/44）承担。

墨色也转到 147°，暖墨压冷底会发脏。`ink` 在新底上对比度 **11.2:1**（配色 B 原版 10.7:1）。

**二稿（同晚）。** 用户看了一稿实拍说「没有完全吸收」，并排比对后差在五处，一起改：
底色色相 147° → **130°**、明度 89 → **86**（一稿偏青偏白）；页底加两块同色系深一档的有机色块 `bgDeep #C2D6C5`

### 1.2 三稿：整页照参考图一的结构做（2026-09-08 晚，用户定）

二稿用户说「这也不一样」，并要求**去掉页底的几何色块**。差的不是颜色，是页面结构 —— 参考图一是一整套版式，不只是配色。三稿把结构搬过来：

- **底栏**：通宽玻璃条 → **悬浮的白色圆角条**（高 60、圆角 22、左右内缩 20、软投影），只有图标没有文字，
  选中项坐在 42pt 珊瑚圆角方块上 —— 全屏唯一的珊瑚实心块。三页共用，主页场景图铺到屏幕最底从它底下穿过。
- **日记页首**照图一分四层：一行 44pt 白色圆角方块按钮（左头像、右搜索）→ 两行衬线大标题（`九月八日 · 星期二` 22 中 / `今天` 34 粗）
  → 一颗信息片（白胶囊，小图标 + 条数）→ 一排筛选片（白胶囊，图标 + 字，横向滚，**真能筛**：全部 / 语音 / 照片 / 只留给自己）。
  为筛选片补了一个 `photo` 图标。
- 分区小标题从衬线 15 中改成衬线 17 粗，和页首同一副字。照片占位块的内圆角从 2 改到 14。
- `GroundBackground` / `bgDeep` 删除。`FlowLayout` 顺手修了量尺寸和摆位置分行不一致的 bug（第二行压到段落上）。

**没动的**：陪伴主页除底栏外原样；我的页只换底栏和小标题；聊天页不变。
