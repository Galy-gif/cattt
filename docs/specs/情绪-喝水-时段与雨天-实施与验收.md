## 做了什么

- **切帧打包** `assets/tools/package_frames_v6.py`：复用 v5 的去底、Lab 调色、缩放，产出 53 帧（`Assets.xcassets/world-v6/`），动作目录新增 10 个动作：`sitLook`、`headTilt`、`groom`、`moodHappy`、`moodSulk`、`moodSadIn`（缩下去的两格，一次）、`moodSad`（循环）、`drinkDown`、`drinkLap`、`drinkUp`（只用 D3 的 1、2、3、6 格）。坐姿锚点在臀部落地线，喝水锚点在后脚；喝水动作的目录条目多一个 `mouth` 字段（嘴相对锚点 43.1pt 前、21.1pt 上）。
- **场景配置** `assets/tools/configure_world_v6.py`（原地改 `world-scene-v4` 与 `courtyard-v4/scene.json`）：
  - 水面：从 P2 取碗口水面椭圆贴进贴图原碗（`world-v6-water.png`），物件 `water`，`visibility: "water"`；碗身不换。
  - 亮窗：S5 按木框十字对齐圆窗（`world-v6-window-lit.png`），物件 `window-lit`，`visibility: "lit"`。
  - 天上的东西：太阳、月亮、五颗星、两朵雨云去底进 `WorldTextures`，不在场景配置里，由 `WorldView` 天空层按时段画。
  - 碗前落脚点 `bowl` 节点（0.167, 0.633）与 m0 相连，用 `mouth` 偏移算得嘴落在碗沿；`bowlHit` 点击热区。
- **模型** `Model/WorldMood.swift`：五个时段、按天随机的天气、三种情绪的原因表与优先级、门口待机池、时段与雨天的去处限制、文案。`Model/Atmosphere.swift`：分级参数关键帧（从四张方向图量的）、按小时插值、雨天叠加。`Model/CatDiary.swift`：团子日记模板。
- **世界层** `WorldScene.swift`：`setConditions` 每秒喂情绪/时段/去处/水碗；门口待机池每 6–15 秒按情绪加权换动作（委屈先播 `moodSadIn`）；喝水一段（走去碗前 → 低头 → 舔 3–5 秒 → 抬头 → 走回门口），全程钉在碗前节点；夜里只在蘑菇屋和猫窝、雨天只在蘑菇屋和树屋之间走；刚倒的水 3–20 秒内去喝，之后一两个小时再喝一次。
- **状态与持久化** `Store/AppStore+Conditions.swift`：`bowlFilledAt`、`lastDrinkAt`、`lastVisitAt`、`createdAt`、雨声开关、团子日记存 UserDefaults；每秒重算；倒水动画；团子日记在 19:30 后写一条。
- **渲染** `WorldView.swift`：拼贴上一层"乘色 + 加色 + 雨天灰雾"的天空分级，独立物件乘时段色，猫单独乘一个更亮的色（夜里仍比地面亮）；天空层画日月星和飘动的雨云；雨丝是 `Canvas` 粒子（减少动态效果时静止）；亮窗不随时段变暗；碗空时水壶图标停在碗边轻浮，倒水时倾斜、落几滴水，水面涨满。
- **界面**：状态句按情绪说原因、按时段和雨天说一句；点猫的反应按情绪换；日记里"团子的一天"暖纸色卡（`DiaryEntry.Kind.cat`），不是今天的进"这个月"；"我的"加"下雨时有雨声"开关。
- **雨声** `assets/tools/make_rain_sound.py` 合成 28.5 秒可循环的雨声（`Resources/Audio/rain-loop.m4a`，227KB），`Store/RainSound.swift` 用 `AVAudioPlayer` 循环、`.ambient` 类别跟随静音开关；只在院子里、下雨时响。工程生成脚本学会收 `Resources/Audio/*.m4a`。
- **调试**：启动脚本加 `time:小时`、`weather:rain|clear|auto`、`mood:calm|happy|sulk|sad|auto`、`bowl:fill|empty`、`drink`、`diary`。

## 和方案不一样的地方

- **碗只做了"满"的水面，没接 P1/P2 两只碗**（验收报告：材质与旁边的红碗不配）。"空"就是贴图原样。
- **D3 只用 4 格**，去掉了有拖影的甩头两格。
- **委屈拆成两个动作**：`moodSadIn` 一次 + `moodSad` 循环，否则每圈都会从坐姿重新缩一次。
- **雨天的天空不用乘色，用一层灰雾**（正常混合）：乘色会把奶白的云染成粉（黄昏时这正好是想要的）。
- **喝水的位置**：猫画在房子前面，从碗的近侧喝，头盖住碗口；没有做"头伸进碗里"的遮挡。
- **团子日记只在 App 开着、过了 19:30 时写**；当天没开过 App 就没有那一条（没有后台）。昨天写过的那条留在"这个月"里。
- 情绪与原因还没传给聊天后端（记忆接口未改），下一轮。

## 同日晚补：过渡动作与远端合并

用户反馈"动画不自然"后补的四处过渡，都不需要新出图：

- **起身 / 坐下**：v5 交付的 N4 第 1–3 格是"侧身站着（朝右）→ 转向观众 → 坐下"，倒放就是起身。新增 `sitToStand`、`standToSit`（各 0.36 秒）。从蘑菇屋门口出发（去别处、去喝水）先起身再走；走到门口先坐下再进待机。出发方向朝左时镜像。
- **委屈退出**：新增 `moodSadOut`（M3 第 2、1 格倒放，0.26 秒），从缩着的姿势坐起来再换待机或起身。
- **待机交叉淡化**：门口待机切换（坐着看你 → 洗脸、打盹 → 开心…）时上一帧 0.3 秒淡出（`WorldView.idleCrossfade`），坐姿之间不硬切。
- **喝完水不瞬间转身**：走回门口后保持走回来时的朝向坐下，下次往右走时自然播转身。

同时合并了远端两个提交（世界层纵深视差 + Metal 着色器、后端 Agent 循环与 Open-Meteo 天气）。冲突四处（文档索引、工程生成脚本、`WorldEngine`、`WorldView`）都是相邻新增，两边保留；天空分级层与日月星云叠在远端的分层底之上、独立物件之下。本机为此装了 Apple Metal 工具链（`xcodebuild -downloadComponent MetalToolchain`）。`WorldDepthTests` 原来把 scene.json 当图片解开会崩，改成只在参数是 PNG 时检查山脊。

连拍验收（0.5 倍速，`outputs/v6-review/sheets/` 未放，本机 scratch）：倒水 → 起身转侧 → 走到碗前低头 → 舔 → 抬头 → 走回 → 坐下，每一步都有帧接上；委屈进出各有两格过渡。
