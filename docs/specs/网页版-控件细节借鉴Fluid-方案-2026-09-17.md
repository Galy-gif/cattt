# 网页版 · 控件细节借鉴 Fluid Functionalism · 方案 · 2026-09-17

用户要求：Fluid Functionalism「能借用的借用，主要是字体大小、fluid 这些细节」。组件参考在 [../参考/Fluid-Functionalism-组件.md](../参考/Fluid-Functionalism-组件.md)。

本方案**只借细节，不装组件**：`web/` 是原生 TS + three.js，界面语言已定（宋体、珊瑚、米白薄面、圆角 20/14/全圆，见 `网页版-院子页面与天气-方案-2026-09-17.md` 3.2），不因此换成 React + Tailwind + Inter。下面的数值都是从它的源码里直接读出来的（`lib/size-context.tsx`、`lib/springs.ts`、`lib/font-weight.ts`、`lib/tokens`、`fluid-hover-highlight.tsx`、`button.tsx`、`chat-message.tsx`、`command-menu.tsx`），不是看文档猜的。

## 1. 借什么、不借什么

| 细节 | 它的做法 | 借不借 | 落到我们这 |
|---|---|---|---|
| 字号按角色分档 | display 28／title 16／subtitle 14／body 13／caption 12；紧凑档每级降 1 | **借思路，数值加 1** | 见第 2 节。它是 Inter 拉丁字的数；中文同字号笔画更密，12 以下读不清 |
| 控件高度与字号绑定 | 36px 配 13px 字、16px 图标；28px 配 12px、14px 图标，"整个控件一起缩，不只缩框" | 借 | 顶栏、地点轨、天色盘各归一档，见第 2 节 |
| 动效三档 | fast 80ms／moderate 160ms（临界阻尼，不回弹）／slow 240ms（回弹 0.12）；**退场是补间、不回弹、快一档**；"东西越大越慢，永远不手写时长" | **借** | 见第 3 节。我们现在控件悬停 0.3–0.4s，偏慢 |

| 字重动画 | Inter 可变字体，字重和光学尺寸 `opsz` 成对调，保证加粗时字宽几乎不变 | **不借** | 正文走系统中文字体栈，没有可变字重轴。中文字是等宽方块，加粗本来就不改字宽，这个补偿在中文里没意义。选中态靠颜色和底色表达 |

## 2. 字号

它的层级思路（按用途分角色、控件高度字号图标一起走）照搬；数值按中文加 1，并且**最小 12px，不出 11**。

| 角色 | Fluid（拉丁） | 我们 | 用在哪 | 现在是 |
|---|---|---|---|---|
| 页面大标题 | 28 | 不动，展示页大字另算 | 首屏标题、章节标题、结尾 | `clamp(40–84)`、`clamp(26–36)`、`clamp(34–68)` |
| title | 16 | 17 | 以后的弹层标题 | — |
| subtitle | 14 | 15 | 章节正文、以后的聊天气泡 | 15 ✓ |
| body（控件字） | 13 | 14 | 按钮 C8、顶栏状态条 C3 | 状态条 13 |
| caption | 12 | 12 | 眉标、地点轨字、天色盘字、页脚元信息 | 眉标 13、地点轨 12 ✓、**天色盘 11** |

要改的只有三处：状态条 13 → 14，眉标 13 → 12（与字距 0.32em 一起看），**天色盘 11 → 12**（按钮最小宽 52px 放得下两个汉字加字距，需量）。

控件高度：顶栏里的可点控件 36px；地点轨行 28px（现在就是）；天色盘按钮保持 44px（它是图标 + 字的上下结构，不在这条阶梯上）。

## 3. 动效时长

分两族，**控件族**借 Fluid 三档，**场景族**保留我们现在的慢速（天色换色 1.2s、入场 0.9s 是院子的节奏，不该跟着变快）。

```css
/* 控件族：Fluid 三档。进场用 --spring，退场用补间且快一档 */
--t-fast: 80ms;      --t-fast-exit: 60ms;       /* 悬停底色、图标描边、高亮移动 */
--t-moderate: 160ms; --t-moderate-exit: 120ms;  /* 地点轨字出现、弹层、选中底色 */
--t-slow: 240ms;     --t-slow-exit: 160ms;      /* 顶栏收起、较大的面 */
--spring: cubic-bezier(0.23, 1, 0.32, 1);       /* Fluid 按钮按下用的同一条 */
/* 场景族：不动 */
--ease / --ease-out，0.9s–1.2s
```

CSS 没有弹簧；fast／moderate 两档不回弹，用上面那条曲线足够。slow 档要 0.12 回弹时用 CSS `linear()` 拟合，或在 JS 里跑（天色盘放大已经有一个二阶弹簧，可复用）。

对照现在：地点轨字 0.3s／0.4s → moderate；天色盘悬停底色 0.3s → fast；顶栏 0.55s → slow。

## 4. Fluid Hover 在地点轨和天色盘上

原生 TS 写一个小模块 `web/src/page/fluid-hover.ts`（约百行），不引 React 和 framer-motion。只实现它的规则，不搬它的代码：

1. 容器里一块绝对定位的高亮层，`transform` 移动（走合成层，不触发重排），宽高只在目标尺寸变化时改。
2. 每帧最多算一次：光标在某项里面 → 那项；不在 → 离中心最近那项（地点轨按 y，天色盘按 x）。
3. 光标进入容器：高亮在目标项上**淡入**（80ms），不从上次位置滑过来；移出：60ms 淡出。
4. 点在两项之间的缝隙：转成对亮着那项的真实点击。
5. 量尺寸用 `offsetTop/offsetLeft`，不用 `getBoundingClientRect`：天色盘按钮有放大 `transform`，后者会量到放大后的框。容器尺寸变化（`ResizeObserver`）时重量。
6. 「减少动态效果」：保留淡入淡出，去掉位移。
7. 键盘聚焦时用同一块高亮（对应它的 `setActiveIndex`）。

**已定（用户 2026-09-17 选 A）**：天色盘现在有「靠近时图标放大」（借自 Sylva）。放大和一块滑动高亮叠在一起可能显得忙。两个选法：

- A（我建议）：保留放大，高亮只做底色、不跟着放大缩放，放大系数从 0.22 降到 0.12。
- B：去掉放大，只留 Fluid 高亮，更安静。

用户选了 A，没有再做 B。

## 5. 判据

- 天色盘、地点轨、状态条字号量出来等于第 2 节表；页面上没有 11px 及以下的中文。
- 控件族过渡时长只出现 80／160／240ms（及退场 60／120／160），`grep` 样式表没有别的控件时长。
- 光标沿天色盘横扫、在按钮缝隙停住：高亮始终在某一项上，录屏逐帧不出现"消失再出现"。
- 在缝隙点击，触发的是亮着那项。
- 打开「减少动态效果」：高亮不位移只淡入。
- 帧率不低于团子小样现有判据（高亮只动 `transform` 和 `opacity`）。

## 7. 实施记录（2026-09-17）

用户批准第 1–5 节，天色盘选 A。同时对第 1 节"不借 Inter、配色、圆角、lucide"有疑问，觉得 Fluid 更好看，先要看对照：`outputs/web-fluid-review/1-我们现在与Fluid默认对照.png`。**这四项仍按已定的界面语言，等用户看完对照再议**，本轮没动。

改了什么：

- `web/src/page/fluid-hover.ts`（新）：第 4 节七条规则的原生实现。
- `web/src/page/page.ts`：地点轨、天色盘各挂一个 `FluidHover`（仅精细指针设备）。
- `web/src/page/style.css`：控件族时长令牌与悬停／按下叠层令牌；状态条 14、眉标 12、天色盘 12（小屏状态条 13）；地点轨字改跟高亮出现；天色盘放大 0.22 → 0.12、位移 −3 → −2px；内缩 1px 的按下效果；图标悬停描边 1.8；焦点环 1.5px；「减少动态效果」下高亮只淡入淡出。

和方案不同的地方：

- 按下松开时外扩恢复用 180ms（Fluid 按钮原值），是控件族三档之外唯一的时长。

- 地点轨高亮用米白 62%（夜里深蓝 50%），不用 4% 黑：地点轨直接压在天上，没有薄面垫着，4% 看不见。
