## 做了什么

| 位置 | 内容 |
|---|---|
| `assets/tuanzi-3d/build_tuanzi.py` | 一条脚本生成外形、贴图、骨骼、蒙皮、眨眼形态键、7 段动作，并导出 glb。做法见同目录 README |
| `assets/tuanzi-3d/compare_refs.py` | 侧面渲染叠 R3 剪影，量四项比例 |
| `web/public/models/tuanzi.glb` | 网页用的模型，1.14 MB |
| `web/src/tuanzi/` | 团子运行时：播哪段动作、走到哪；看光标、眨眼、尾巴弹簧；四版材质与描边；滑步和切换跳变的实时量测；调试面板 |
| `web/tuanzi.html` | 团子调试页。`pnpm --dir web dev` 后打开 `/tuanzi.html` |

与院子那边并行（决策补记第 6 条），分文件：团子只动 `assets/tuanzi-3d/**`、`web/public/models/tuanzi.glb`、`web/src/tuanzi/**`、`web/tuanzi.html`；`web/vite.config.ts` 的多页入口由团子这边配。

接口在 `web/src/tuanzi/index.ts`：`loadTuanzi(url)` 得到的团子有
- `root`、`update(dt)`；
- `walkTo(point)`、`walkAlong(points)`：返回 Promise，走到或被打断时 resolve，带 `interrupted`；
- `sit()`、`stand()`、`lookAt(point | null)`；
- 只读 `position`、`facing`（−π 到 π，0 = 朝 +Z）；
- `appearance.setTint(color)`、`appearance.setGlow(amount)`。

## 和方案不一样的地方

1. **色调映射用 Neutral，曝光 1.4，不用 ACES。** 同一盏主光下量额头颜色：Neutral 为 (244,148,66)，R1 身体取样为 (248,150,42)；ACES 发黄发灰，为 (226,161,77)；AgX 更淡，为 (213,164,120)。
2. **加了着地锁脚，走着可以转弯；急弯先停再原地转。**
   - 起因：边走边转时整只猫绕中心转，离中心约 12 cm 的着地爪子会被扫开，不锁脚时每秒转 45° 实测滑步 6.9% 身长。第一版因此把边走边转限到每秒 6°，院子那边沿弯路走时每个节点前都要减速打转。
   - 现在：`FootLock` 在爪子着地时记下它的世界位置，用两节腿的解析 IK 按回原地，只锁水平位置；偏离超过 5 cm 就放开，让这一步迈出去。
   - 边走边转放到每秒 80°；偏差大于 60° 才停下原地踏步转，转到 6° 以内再走。
   - 新增 `walkAlong(points)`：瞄准路上前方 0.2 m 的点，缓弯边走边转；前方 0.6 m 内有大于 60° 的拐点时，对准拐点走、在拐点停稳，再原地转，不抄近路切弯。
3. **看光标最多转 45°，并把胸收到头后下方。** 第一版转到 60° 时，下巴扫过胸口，把胸口皮肤扯出褶。
4. **趾缝每只爪两道。** R1 放大后是两道线分出三趾，方案里没写数量。
5. **额纹、身纹、尾环比第一稿宽约一倍。** 第一稿按 R1 像素估的宽度，渲染出来明显偏细，对着 R1 调过。
6. **外形用距离场加 openvdb 抽面，不用 metaball（方案 4.3 第 2 步）。** metaball 的场是叠加的，重叠处会鼓包，尺寸也难精确控制；距离场可以按米给尺寸，交界圆角半径也能单独定。
7. **贴图 2048×2048，按烘出来的表面位置画纹样（方案 4.3 第 3 步写的是 1024、按骨骼局部坐标画）。** 1024 下嘴和趾缝只有两三个像素宽。改后 glb 仍是 1.14 MB。
8. **蒙皮权重自己算，不用 Blender 自动权重（方案 4.3 第 5 步）。** 按部位距离场分区，再沿骨链插值，部位交界按距离过渡，头和身子之间的过渡加宽到 3 cm。好处是每一处归哪根骨头都说得清。
9. **身份比例改用侧面剪影叠 R3 的四项比例（方案第 6 节写的是人工标点的基准表）。** 剪影能自动量、每轮都能重跑。正面没有真正的正面参考图，所以没量。
10. **10 秒录屏没做。** 浏览器面板被隐藏时逐帧回调暂停，录不出连续动作；动作改用脚本逐帧推进后截静帧（`4-网页-姿势与动作.jpg`）。

## 这轮踩到的坑

- **Blender 5 新建形态键的值默认是 1**，导出后眼睛一直闭着。建完要把值设回 0。
- **makeClipAdditive 会原地改关键帧。** Blender 导出器会让几段动作共用相同的常量关键帧数组，three.js 的 `makeClipAdditive` 又直接在数组上改值；不先复制，所有动作的位移和缩放都变成 0，骨架缩成一个点。
  - 排查时我一度以为是 NLA 轨道静音导致导出全 0，写了绕开的代码。后来实测静音轨道导出正常，绕开代码已删，注释也改了。
- **一次只挂一个外部对照很难定位问题**：换成"截图叠剪影 + 数值"之后，每轮外形调整都有依据（`compare_refs.py`）。

## 遗留

| 事 | 现状 | 打算 |
|---|---|---|
| 坐下时描边露深色碎斑 | 外扩背面描边在肚子挤压处穿出 | 描边宽度按蒙皮后法线算，或坐姿时减宽；要看用户选不选描边版 |
| 轮廓绒毛在胸口读成细碎噪点 | 离近看像撒了沙 | 纤维改成沿法线的短线状，或降密度；也看用户选不选 |
| 纹样对比度比 R1 低 | 身纹、额纹偏淡 | 看图后调 `COLOR_STRIPE`／`COLOR_RING` |
| 正面看腿显长、头不够圆 | 侧面比例已过线，正面没有参考图可量 | 用户看图后定要不要改 |
| 坐下时尾巴没绕到身前 | 落在身后偏左 | 调 `SIT_TAIL_PATH` |
| 抖耳朵、原地转身时爪子的滑动 | 都没量，也没截图；原地转时锁脚也开着，但量测只统计走路 | 下一轮补 |
| 夜晚 + 雨天团子几乎全黑 | 院子那边第一轮反馈 | 已留 `appearance.setTint(color)`（整体乘色）和 `appearance.setGlow(0–1)`（按贴图自发光），院子第二轮调光时一起定数值 |
| 1440×900 真实帧率 | 见判据表 | 浏览器面板可见时补量 |

## 怎么复现

```bash
# 仓库根目录：生成模型（约 4 分钟；外形没改时加 --reuse-texture 约 2 分钟）
blender -b --factory-startup -P assets/tuanzi-3d/build_tuanzi.py -- --until=all
python3 assets/tuanzi-3d/compare_refs.py final
# 网页
pnpm --dir web install && pnpm --dir web dev   # 打开 http://localhost:5173/tuanzi.html
```

调试页网址参数：
- `view=front|side|three-quarter`：机位；
- `surface=felt|soft`：表面；
- `outline=0`：关描边；
- `fuzz=0`：关绒毛；
- `still=1`：关实时层；
- `pose=<动作名>&t=<秒>`：定格在某段动作的某一秒。

控制台里 `__tuanzi` 可以拿到 cat、stage、metrics。
