# 底部导航改版：日记进信箱、Profile 上右上角

2026-09-10。状态：方案待评审，未实施。用户直接请求：日记 Tab 换成大地图上的一个信箱，点开像一张纸弹出今天的日记；Profile 改到右上角一个按钮；仍符合 iOS 设计规范。先讨论再写代码。

## 现状（读代码得到的事实）

- Tab 栏三项：陪伴 / 日记 / 我的（`Features/Shell/TabBarView.swift`），聊天和创建流程不显示。日记未读红点是 `AppStore.diaryDot`。
- 路由是 `AppStore.Screen { home, chat, diary, me }`，`RootView` 按它切整屏。日记页和我的页都为 Tab 栏让出 `TabBarView.height`。
- 世界层物件走 `world-scene-v4.dataset/data.json` 的 `objects`，每个物件有 `image / rect / depth / hitRect / target / motion / parent`。点物件的命中在 `WorldView.tap`，带 `target` 的物件让猫走过去。`motion` 已有 `nest`（吊窝摆）和 `flower`（花茎弯）两种绕轴旋转。
- 世界画布 `.transaction { animation = nil }`，物件状态变化不走 SwiftUI 隐式动画，要动就得逐帧算。
- 蘑菇屋是默认起点（`destinations[0]`，相机 0.15），猫开局就在那。

## 一、信箱：替代「日记」Tab

### 1.1 放在哪

**推荐：蘑菇屋门口，石板路左侧的草地上。** 归一化脚点约 `(0.085, 0.665)`，高约 0.11（约 93pt，比 76pt 的猫高一点点，家门口信箱的正常比例）。

理由：
- 开局镜头就在这（相机 0.15，可见 0–0.30），首次进院子就看得见，不用找。
- 「家门口的信箱」语义最直，团子的家在蘑菇屋，信箱在家门口。
- 猫的路线 m0→m1 往右走，不会穿过信箱；房子障碍区在 x 0.07–0.23、y 0.36–0.625，信箱脚点在它下方偏左，不冲突。

备选：栅栏边、石板路右端（约 `(0.965, 0.62)`）。「院门口」也顺，但在最右，要拖两屏才看见，首屏没有入口。

### 1.2 状态与信号

| 状态 | 表现 |
|---|---|
| 没有新东西 | 信箱旗子放下 |
| 团子来看过 / 留了一句（原 `diaryDot`） | **旗子立起来**（珊瑚色，全场景唯一的珊瑚实心块之一），加一次 0.4s 的轻微弹起 |
| 事件发生的那一刻 | 沿用状态条那句话：「团子在你的日记上留了一句」，2s 后回到常态句 |
| 打开信箱 | 旗子放下，`hasMail = false` |

`diaryDot` 改名 `hasMail`。旗子是持续信号，状态条那句是瞬时信号；镜头不在信箱这边时靠状态条告诉你，不再加第三个入口。

### 1.3 物件与命中

`data.json` 新增两个物件：

```
mailbox        image world-v5-mailbox   rect 脚点 (0.085,0.665) 宽约 0.05 高约 0.11   depth 0.665   action "mail"   hitRect 比图大一圈（不小于 46pt）
mailbox-flag   image world-v5-mailbox-flag   parent mailbox   motion "flag"   depth 0.666
```

- `WorldScene.Object` 加一个可选字段 `action: String?`（Codable 可选，旧 JSON 不受影响）。`WorldView.tap` 在查 `target` 之前先查 `action == "mail"`，命中就 `store.openMailbox(anchor:)`，把信箱口的屏幕坐标带出去给动画当起点。
- `motion == "flag"`：绕旗子底部轴旋转，立起 0°、放下 80°。因为画布关掉了隐式动画，角度由 `AppStore` 的一个 `flagAngle` 在世界 tick 里按 0.3s 插值到目标值，`objectLayer` 只读值。
- 猫从旁边走过时的前后关系靠 `depth` 0.665 和猫的脚 y 自然排序，不加遮挡片。

### 1.4 美术

毛毡风信箱，两层透明 PNG：箱体+立柱一张、旗子一张（旗子单独出，旋转轴在旗座）。先用代码画一个占位的矢量信箱把位置、热区、动画全部跑通，再按 `workflow_codex_image_generation` 的规矩委托出图换上。占位阶段就能验收交互，美术不阻塞工程。

## 二、纸从信箱里抽出来：日记的呈现

### 2.1 两条路

| | A. 自定义「抽纸」过场（推荐） | B. 系统 `.sheet` + 信箱开盖小动画 |
|---|---|---|
| 观感 | 纸真的从信箱口长出来、转正、铺满 | 信箱盖子开、纸探头一下，然后标准 sheet 从底下升起 |
| 符合 iOS | 过场自定义，但落定后的行为全部照 sheet：抓手、下拉关闭、点遮罩关闭、右上角关闭钮 | 完全原生 |
| 成本 | 中：一个 `PaperSheet` 容器 + 锚点插值 | 低 |
| 键盘/无障碍 | 要自己处理（现有 `BottomSheetScrim` 已经处理过键盘） | 免费 |

HIG 对自定义过场的要求是「可理解、可用标准手势关闭」，A 满足。用户原话是「像一张纸一样弹出」，A 是这句话的完整版，B 是折衷版。推荐 A。

### 2.2 A 的动画规格（390 × 844 参考机）

1. 点信箱：信箱 0.12s 缩放到 1.06 再回来，轻触感反馈。旗子放下。
2. 遮罩 `Palette.overlay` 0.25s 淡入。世界画布不缩放（它是逐帧画布，缩放会多一层合成，先不做）。
3. 纸：起点在信箱口，宽 60% 屏宽、高 30pt、旋转 −6°、透明度 0；终点顶边在 `safeTop + 12`、通宽、贴到屏幕底、旋转 0°。走 `spring(response 0.45, dampingFraction 0.86)`。实现上是一个 `progress` 0→1，用 `scaleEffect(anchor: .top)` + `offset` 从锚点插到终点，避免 matchedGeometry 跨层级的坑。
4. 纸上内容在 `progress > 0.6` 后 0.15s 淡入，不跟着缩放，文字不糊。
5. 关闭：拖抓手或页首下拉 >120pt 或速度 >800 → 纸向下滑出（标准 sheet 行为）；点遮罩或关闭钮 → 纸缩回信箱口（0.3s easeIn），对称。
6. 系统「减少动态效果」打开时：整段换成 0.2s 交叉淡入淡出。

纸的样式：白卡 `Palette.card`，顶部两角 `radiusLg` 18（和 iOS 26 sheet 的角接近，不追求完全一致），顶部居中一条系统式抓手（36 × 5，`Palette.rule`）。**不用暖纸色** —— 暖纸色（`Palette.paper`）是「团子写的东西」的语义，日记本身是用户的，留言纸在日记里仍然是暖色，对比关系不变。

### 2.3 纸上放什么

就是现在的 `DiaryTodayView`，改成 `DiaryPaperView`：

- 页首第一行：左边搜索钮保留，**右边换成关闭钮**（44pt 玻璃圆角方块，`Icons.close`）。原来左边的团子头像去掉 —— 头像现在住在院子右上角，不重复。
- 两行衬线大标题、信息片、筛选片、碎片列表、「这个月」、「记一下」全部原样。
- 「记一下」的 `CaptureSheet` 仍是底部抽屉，叠在纸上面（提到 `RootView` 那层）。
- 去掉给 Tab 栏让出的底部高度，改让出安全区 + 16。
- 留言纸上的「聊聊」→ 关纸、进聊天（`openChat(from:)` 顺手把 `mailboxOpen` 置 false）。

## 三、Profile 上右上角

### 3.1 按钮

院子右上角一颗 44pt 圆形玻璃钮，里面是团子头像（`tuanzi-canonical`），和日记页首原来那颗完全一样的 `IconTile(size: 44, circular: true, glass: true)`，`interactive: true`，无障碍标签「我的」。位置：右边距 16，纵向和状态条胶囊中线对齐（状态条 `designTopInset(58)`，钮的顶部 inset 取 50）。状态条现在左右各留 60，钮占 16 + 44 = 60，刚好不碰；把状态条留白改成 64 留一点缝。

这是 App Store「账户」按钮的位置和做法：右上角头像，点开是 sheet。

### 3.2 打开方式

**原生 `.sheet`，`.presentationDetents([.large])`**。`MeView` 加一行「完成」（或右上角关闭钮，二选一，推荐「完成」，和 App Store 一致）。去掉给 Tab 栏让出的底部高度。长按「帮助与关于」进创建流程的调试入口保留，进创建流程前先关 sheet。

我的页不需要「像纸一样」，它是设置页，原生 sheet 就是对的。

## 四、Tab 栏还剩什么

日记走了、我的走了，Tab 栏只剩「陪伴」一项。一项的 Tab 栏不成立，**推荐整个去掉**：

- 院子本来就是 app，聊天是场景上的「聊会儿」胶囊，日记是信箱，我的是右上角。四个去处都在院子里，不需要底栏。
- 场景铺到屏幕最底，「聊会儿」「找团子」从现在的 bottom 118 / 124 下移到 `safeBottom + 24`（约 58），话题卡从 186 下移到约 120。
- `TabBarView.swift` 删掉，`Icons.tabDiary` 留着（筛选片在用），`Icons.tabCompanion / tabMe` 删。

备选：保留两项「陪伴 / 聊天」。不推荐 —— 聊天已经有场景上的主按钮，再进 Tab 栏是同一件事两个入口，而且聊天屏本来就是隐藏 Tab 栏的全屏。

- 纸打开时「记一下」抽屉能叠上来，键盘顶得动；留言纸「聊聊」能进聊天，返回院子时纸已关。

- 「减少动态效果」开启时无位移动画。
- 现有 `ios/Tests` 四组测试全过；`validationErrors()` 对新物件不报错。
