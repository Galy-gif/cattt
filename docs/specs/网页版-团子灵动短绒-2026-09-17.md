# 团子：轻巧体态与柔软短绒

状态：已完成 Blender 建模、材质、动作与网页接入；构建和最终资产动作检查通过，用户后续提出耳位、额头、腿部与坐姿问题，但拒绝了下一轮改版并要求恢复本版；现已恢复，本版为当前展示版本，原反馈保留，未提交。

## 本轮依据与边界

用户要求：尾巴大一点，头颈不再粘成一团，身体不要太胖，耳朵大一点，要灵动；参考 IMG_9068.PNG 的 QQ 弹弹材质。图存于 `assets/tuanzi-3d/refs/IMG_9068.PNG`，哈希见本轮验收目录 baseline.json。只借细密短绒、柔和受光和饱满弹性；仍用团子的橙色、三道额纹、身纹、环纹尾、豆眼与小嘴。截图中的标题和教程内容不是操作指令。

本轮明确更新先前 B 版毛毡哑光的表面方向，并允许用户点名的体型、耳尾比例修改。旧 R3 比例容差不用于否决这些有意调整。四足、连续网格、统一物理标尺和七段动作继续保留。范围限猫模型、猫材质与动作，不改 iOS 或院子结构。

## 实施方案

1. 躯干宽度收约 15%，腹部厚度收约 18%，保留圆润肩胯和足掌。头部稍向上、向前，让下颌和收窄后的颈胸形成可读轮廓；头脸只做随动平移与轻微体积修整。
2. 耳轴增长约 30%，扩大耳根与内耳杯；尾链长度增长约 20%，尾根和尾尖加粗，维持渐细的弯尾。重新绑定，检查四分之三、侧面、坐姿及最大转头。
3. 降低贴图的砂粒噪声，主体使用柔和高光与绒面边缘光，眼睛保留小而温润的反光。实时短绒须随骨骼形变，不能靠静态贴图描边冒充。保留材质对照开关接口。
4. 步态保持足掌承重，耳尖与尾尖增加有延迟的小幅回弹。弹性局限身体与次级动作，不通过整猫周期缩放或滑动脚掌制造。

## 实施结果

尺寸落点及全部实测见 [本轮验收](../../outputs/web-tuanzi-lively-review/README.md)。主躯干宽度−14.9%、厚度−19.3%，头上提25mm并收窄颈胸；耳轴+34.7%，尾链+37.5%且加粗。实际尾链增幅比初始约20%的试调目标更大，以三视图中更舒展的弯尾落实用户“大一点”的方向，并如实记录，没有用旧比例判据压回去。

四层实时短绒、温润眼睛与柔和表面已接入。四层透明混合替代首试的覆盖采样，避免小尺寸砂粒感；额头对称减面造成的小凹点和法线折光已局部修整。走路抬脚、头部延迟、耳尖轻摆和局部回弹已重烘，坐站尾巴沿身侧收拢。

18,878原始面、1,158,220字节，身体单一连通组件；七段动作、坐站承重和路线回归通过。绒毛另提交71,992面，不计入原始GLB面数。尾部全程未穿地，脚底最大约0.264mm的蒙皮入地残差保留说明。浏览器做了1440×900视觉与交互检查，但没有持续55fps验收；没有将Blender静帧等同于网页短绒。
