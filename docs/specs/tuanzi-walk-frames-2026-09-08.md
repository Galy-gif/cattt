## 1. 身份基准

唯一真相源 `assets/tuanzi/canonical/团子-canonical-v1.png`。每帧必须能被认出是它：

- 橘虎斑，额头三道条纹，背部横纹
- **环尾**（尾巴上一圈圈深色环）—— 最强识别特征，走路时始终可见
- 圆身短腿偏胖，不是流线型
- 耳内浅粉，耳尖略圆
- **不画嘴**

## 2. 为什么九姿态那批不能直接用

`assets/tuanzi/world-layer/01-nine-poses.png`（首轮验收未通过）只能当画风和体型参照，
以及之后「落点姿态库」的基础。不能当走路帧：

| 问题 | 说明 |
|---|---|
| 每格都带物件 | 篮子、碗、石头；走路帧只能有猫 |
| 全是 3/4 视角 | 没法左右镜像 |
| 第 4、5 格残留小嘴形 | 上一轮明确的未过项 |
| 底色不匀 | 不是精确均匀的 `#C6D9C4`，裁片底色边界可见 |

## 3. 画布

- **PNG，优先真 alpha**。脚本检测到真实透明会原样保留 RGBA，不做二次抠色。
- 给不了透明就用纯色底 **`#C6D9C4`**（脚本 `sage` 模式），整批同一个精确值。
- 统一画布 **1254 × 1254**（与已封版的六张表情源图同规格）。
- 脚底踩同一条 y，帧间偏差 ≤ ±15px。
- **猫可见高度帧间差 ≤ 2%** —— 逐帧路线的命门。
- 四边留白给够，尾巴甩到最外侧不贴边。

禁止：投影、地面线、脚边草笔触、背景纸纹、渐变、棋盘格、边框。
阴影在代码里做，它要跟着猫在场景里移动。

## 4. 动作 — 六帧循环，只出向右

向左在代码里 `scaleX(-1)` 镜像：省一半出图，且左右绝对一致。

| 帧 | 动作 | 身体高度 |
|---|---|---|
| 01 接触 | 左前爪落地，右后爪蹬地 | 中 |
| 02 下沉 | 重量压上，身体最低 | 低 |
| 03 通过 | 另一侧腿摆过身体正下方，身体最高 | 高 |
| 04 接触 | 01 的左右相反 | 中 |
| 05 下沉 | 02 的另一侧 | 低 |
| 06 通过 | 03 的另一侧，接回 01 | 高 |

起伏幅度（最高帧与最低帧的可见高度差）先按**猫身高的 3–5%**。
这是从骨骼 demo 量的起点值，真帧回来后再校。头部相位比身体晚约 1/4 拍。

视角：**严格正侧面**，朝右；光源左上（与六张场景的下午光一致）。

## 5. 出图节奏 — 先横条，再单张

1. **第一轮** 一张六格横条，总宽 ≥ 3072（每格 ≥ 512）。一次生成，一致性最好。
   **只验动作，不进产线。**
2. **第二轮** 动作定稿后按帧出单张全幅 1254×1254，补回分辨率，进产线。

把一致性风险按在便宜的那一轮：横条重掷是一张图，单张重掷是六张。

## 6. 命名与落位

```
tuanzi-walk-sheet-v1.png          # 第一轮横条
tuanzi-walk-r-01.png … -06.png    # 第二轮单帧，r = 向右
```

- 源图 → `~/Documents/ChatGPT/猫/outputs/`（脚本 `--source-root` 指向这里）
- 副本 + `prompt.md` → `assets/tuanzi/world-layer/walk-v1/`

## 7. 验收数值

| 量什么 | 阈值 |
|---|---|
| 猫可见高度，帧间差 | ≤ 2% |
| 脚底 y，对齐后偏差 | ≤ 0.5 输出像素 |
| 主色 H 差 / S 差 | ≤ 3° / ≤ 0.03 |
| 非猫像素与 `#C6D9C4` 的距离（纯色底时） | ≤ 2 |
| 投影 / 地面线 / 纸纹 | 0 处 |
| 尾环可见的帧数 | 6 / 6 |

任何一帧不过，**只重掷那一帧**，已过的不动、不重生成、不替换。
