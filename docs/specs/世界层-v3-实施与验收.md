# 世界层 v3：找猫镜头与物件互动

2026-09-10。用户批准《找猫镜头与场景互动优化方案》后实施。范围为陪伴世界、镜头、角色动作与场景配置。

## 已接入

- **找猫镜头**：取消对子物件位置的 SwiftUI 隐式动画，镜头由唯一显示坐标逐帧推进。回到猫与跟随使用同一位置、速度，允许途中拖动接管；连续点击更新同一目标。跟随死区不再阻止镜头到达世界边界。左右边缘严格限制，减少动态效果时直接定位。
- **背景加载**：提前准备当前视口与运动方向相邻地块，保留旧地块直到替代素材就绪。静态物件与轻量干净底板先准备，初次呈现不显示缺少物件的空场景。异步解码结果按实际需要接收，不再因整批代号变化把仍有用的图片丢掉。普通纹理不使用多余的遮罩，小物件按最大实际取景需求解码。
- **磨爪**：抓板加长，猫移到抓板右侧并朝向板面；背侧动作含搭爪、磨爪、放爪，保持后脚基线。前爪在实际截图中落于板面。
- **道路与转身**：沿既有道路图生成有走廊校验的曲线路段，按近似弧长推进步态；控制转弯峰值速度，反向时先播放转身。新增栅栏接近段，与最终站位一致。
- **树上吊窝**：看窝、蓄力、跳起、抓沿攀入、窝口眨眼、睡眠、爬出、跳下与落地。吊窝从原树资产按轮廓拆出并扩大，前沿与洞口遮挡角色；接触后轻摆衰减，休息时有轻微呼吸。
- **栅栏与花**：闻花、抬爪轻拍、花茎回弹与追看；随后跳上独立支撑横梁，站稳、趴下看风景或睡觉，再出栏落地。花朵为单独生成的透明物件，没有挖走原栅栏的一块背景。
- **中途换地点**：入窝／上栏过程中保留最后一次请求，在可退出阶段完成离开与落地后再寻路，不能从高处直接进入地面走路。切页／后台暂停世界与显示时钟，回来不补跑离开时间。

## 工程与复现

- `ios/Maomao/Model/WorldCamera.swift`：可测试的显示镜头。
- `ios/Maomao/Model/WorldInteraction.swift`：树窝和栅栏完整行为序列、支撑点、摆动与打断。
- `ios/Maomao/Model/WorldScene.swift`：场景数据、寻路、曲线与移动状态。
- `ios/Maomao/Store/WorldTextureCache.swift`：有限视口解码与静态物件缓存。
- `ios/Maomao/Features/Home/WorldView.swift`：统一世界坐标绘制、物件裁切、洞口遮挡与命中测试。
- `assets/scenes/courtyard-v3/scene.json`：本轮独立配置，旧 v2 文件保留。
- `assets/tuanzi/world-v3/`：两张动作原图、独立花朵源图、原始提示词和基础动作配置。图片通过内置 imagegen 生成，Swift 导入脚本执行色键、切格、轮廓分离与打包。

从项目根目录运行：

```sh
swift assets/tools/package_world_v3.swift
python3 assets/tools/configure_world_v3.py
sips -Z 1800 assets/scenes/courtyard-v2/ground-native.png --out ios/Maomao/Resources/WorldTextures/world-v3-ground-preview.png
python3 assets/tools/validate_world_v3.py
python3 ios/generate_project.py
```

修改前 Swift、原动作配置与工程文件保存在 `outputs/world-v3/baseline/`。本地工程没有 Git 仓库，本轮没有提交或发布。
