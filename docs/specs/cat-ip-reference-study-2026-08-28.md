## 分析结论

共同方向可概括为：低细节密度，高情绪辨识度；让造型服务于表演。

1. **简化的是装饰，不是识别。** 减少逐根毛、复杂反光和零碎花纹，但保留有特点的头身比例、耳朵、脸部色块、爪子或尾巴。不是所有部位都做大，而是明确主次。
2. **表情突出不等于眼睛永远很大。** 大眼可以亲和，小眼加宽嘴可以憨，闭眼加轻摆可以投入；关键是眼形、视线、嘴型、耳位和身体是否表达同一状态。
3. **性格需要进入姿态。** 中性站姿只能说明长相，不能充分说明角色。动作要让人读出它正在试探、用力、犹豫、得意或沉浸；不要以机械循环或大量粒子代替反应。
4. **3D 与简约并不冲突。** 可以保留柔和体积、触感和光照，同时用大色块、清晰轮廓和少量毛束组织画面。现阶段不因此改成纯 2D，也不预定引擎或绑定方式。
5. **要有稳定的识别点，也要留出表达范围。** 同一视觉体系需支持不同个体气质，不把所有猫固定为同一种坏笑、呆萌或兴奋表情，不以花色决定人格。

## 对下一轮设计的建议（未定案）

上一轮奶牛猫图已加强毛发层次、蓬松尾巴和真实触感，但尚未展示独特的表情／姿态体系。新一轮应先在简单色块或线稿阶段验证“角色是否成立”，再决定毛发和材质。

- 先探索不同轮廓与五官组合，不先给同一个模型换几种毛色。
- 奶牛猫黑白色块、白胸口／白爪和大尾巴可作为候选识别资产，但保留哪些需重新选择，不是本轮定案。
- 每个方向建议同时展示中性、好奇、嫌弃、得意、委屈、放松等状态，检验表情幅度与识别一致性；这不是已批准的制作清单。
- 动作例子只作设计思路：好奇时先侧耳，再探头；想亲近时身体靠近但眼神回避；不满时转头、尾巴末端轻动。需后续根据具体气质与画面验证，不当作猫行为学事实。
- 验收可用小尺寸识别、纯色剪影、去掉字幕与特效仍能读懂状态、换表情仍认得同一只猫等方法。

建议工作顺序：轮廓与比例 → 表情和关键姿势 → 短动作试验 → 材质精修。
