# 猫猫小院 v2：实施与验收

2026-09-09。范围是陪伴世界与猫动作，SwiftUI、iOS 17 最低部署版本不变；聊天、日记、室内、天气未扩展。

## 已实施

- 上下扩图、完整树冠，镜头只左右移动。第二稿树冠偏扁后，按用户反馈改为更高的圆顶叶簇，原始比例摆放，并在顶部状态条下留出空间。
- 原定 5600×3360 首稿调整为 3:2 构图。15 块原生生成地面以最低实际像素密度向下统一，得到 5166×3444；没有把低清全景插值成高清。树冠与树干又分区补细节，透明树为 1604×1649。合成全景输出 4302×2868，逐物件检查均未上采样。源图、透明件、生成记录保留。
- 地面、大树、猫抓板、蘑菇屋、草丛后片与前片、猫窝与前沿、栅栏独立。地面底板已填补物件原位置。猫抓板坐标相对树定义。
- 世界配置保存道路图、宽度、障碍、六个互动站位、接触区、物件深度。Dijkstra 沿路寻路，不可达时保留原位；移动中换目标保留最后一次请求，减速后从实际位置沿当前道路重新规划。
- 走跑按实际位移推进帧，纵深接近切换前斜／后斜步态。接近树后搭爪、磨爪、放爪；草丛侧面进入，前草真实遮挡；猫窝前沿遮挡下部。池塘在岸边，房屋只在门前活动。
- 自主普通停留 45–90 秒、门前打盹／猫窝 120–180 秒；磨爪 6–10 秒。追尾先走到草旁空地，16 帧、12fps、两圈后安静待机。
- 追尾使用八个转向关键帧＋八个中间姿态；困倦八帧周期 4 秒；新增两组六帧斜向步态及四帧搭爪／放爪。旧走路尾巴修补资源未覆盖。
- 地点轨只移动镜头；自由镜头不会被自主行为夺走，「找团子」恢复跟随。离开陪伴页／后台暂停，不补跑离开时间。
- 高清纹理改为普通 bundle PNG 按视野加载；仅保留可见区域与相邻区域，避免 UIImage(named:) 常驻整个全景。
- Debug 支持指定地点、暂停、逐帧、动作预览、固定种子、脚本切页与状态快照。场景和动作资源在加载时检查完整性。

## 工程入口

- `ios/Maomao/Model/WorldScene.swift`：纯 Foundation 场景配置、路径、可复现模拟。
- `ios/Maomao/Store/WorldEngine.swift`：30Hz 时钟、页面／后台生命周期、调试数据。
- `ios/Maomao/Features/Home/WorldView.swift`：分层绘制、脚底锚点、点击／拖拽。
- `ios/Maomao/Store/WorldTextureCache.swift`：有限视野纹理缓存。
- `assets/scenes/courtyard-v2/scene.json`：当前场景配置。
- `assets/tools/build_world_v2.py`：确定性切帧、透明导出、场景打包。
- `assets/tools/stitch_world_v2.py`、`stitch_tree_v2.py`：原生细节块合成，只向下统一密度。
- `outputs/world-v2/review/actions.html`：动作播放与逐帧检查。
- `outputs/world-v2/baseline/`：修改前文件与 SHA256，原 v1 图像目录保持原样。

重新打包顺序：`python3 assets/tools/stitch_tree_v2.py` → `python3 assets/tools/build_world_v2.py` → `python3 assets/tools/stitch_world_v2.py` → `python3 ios/generate_project.py`。本地生成图保留在 `outputs/world-v2/review/` 和 `tiles/`，这些是可复现输入，不能只复制 Swift 文件。

## 验证记录

- 纯 Swift 验证六地点全部 30 条有向路径，每次 tick 检查脚底可走与障碍；覆盖最后目标优先、暂停、钻草与 600 秒固定种子一致性。测试入口 `ios/Tests/WorldSimulationTests.swift`。
- Xcode 26.6 / iOS 26.5 Simulator 构建；最低部署 iOS 17。最终构建结果见 `outputs/world-v2/final-build.log`。
- 首轮五分钟：9000 次更新／300.36 秒；平均模拟更新 0.172ms，最大 3.48ms；计时器间隔 P95 34.24ms。RSS 107MB 起、最高 290MB、结束 141MB，随视野加载后回落。数据是模拟状态更新时间和模拟器进程内存，**不是 GPU 渲染帧率，也不代表 iOS 17 真机测试**。
- Pro、Pro Max 已取得真实运行截图，圆顶树冠在顶部状态条下有留白，道路与猫高于底栏。17e 在启动画面阶段失败，安装返回 Mach error -308（server died），未取得有效 App 截图，不能宣称通过。
- 生命周期命名快照确认：离页前世界时间 0.89 秒，聊天页停留后仅 1.05 秒且 paused=true；回来后继续至 3.58 秒；手动暂停快照 3.68 秒，恢复后 5.69 秒。见 `lifecycle-*.json`。
- 运行证据和机型取景放在 `outputs/world-v2/review/`。资源视觉验收仍需结合实际播放确认，不能用“帧数齐全”代替连续性观感。

## 边界与回退

本地没有 git 仓库，未创建提交。旧资产与基线文件保留，可恢复旧 Swift 文件与项目配置。新版资源是独立目录，没有覆盖旧猫动作。

当前只有 iOS 26.5 模拟器运行环境；iOS 17 只做编译部署兼容检查，不宣称真机验收。生成图仍应保留视觉复审：尤其追尾的转向观感（已提供连续十圈录屏）、打盹身体的轻微形变、不同动作之间画法差异，以及物件透明毛边。当前已接入的是可运行的 v2 候选，未发布到任何外部渠道。
