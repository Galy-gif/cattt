# 猫猫 App · 原型图清单与第一批提示词

## 一、先说一个技术现实

**出图模型渲染中文界面文字几乎必然是乱码。**生成出来的原型图只能当**版式和风格参考**，上面的字不可信。

所以整条路径应该是：

`生成原型图（定版式与风格）→ 人读图确认 → 用代码搭可点击 demo（文字才是真的）`

不要指望生成的图能直接当交付物，也不要在图上抠文案。**提示词里我把文字量压到最低**，只保留结构必需的标签，就是为了减少乱码干扰。

## 三、第一批提示词（创建流程 8 屏）

**用法**：把下面【通用块】和全部八个【屏块】一次性发给 ChatGPT，要求**八张分别输出，不要拼成一张网格**。

配色请把 `【配色】` 一段替换成你最终选定的那一套（四选的色值见配色对照文档）。下面先填的是方向 B「院子里」。

---

### 通用块

```
Design mobile app UI screens for a companion cat app. Output each screen as a
SEPARATE full-size image, 390 x 844 (iPhone logical size). Do NOT combine them
into a grid or contact sheet.

WHAT THE APP IS
A user adopts one cat that lives in a fenced garden and goes about its own
life. There are no tasks, no daily check-ins, no levels, no coins, no feeding
pressure. The tone is quiet, warm and unhurried. The interface should feel
like a well-made paper object, not like a game HUD.

VISUAL SYSTEM
【配色】
  page background      #DCE6D6
  card / surface       #F4F2E6
  divider / border     #C3D0BA
  primary text         #26301F
  secondary text       #6E7A63
  accent / primary CTA #C25A3E
  cat fur              #E3A05C

Typography: a serif for headings with real character (Songti / Noto Serif SC
feel), a clean sans for body and controls. Headings are noticeably larger than
body; plenty of line spacing.

Components: 4px corner radius, 1px hairline borders, NO heavy drop shadows, NO
glassmorphism, NO gradients. Primary buttons are solid accent with a 2px darker
bottom edge, full width, 52px tall. Secondary actions are plain text with a
thin underline. Icons are thin hand-drawn line icons, 24px, rounded ends,
NEVER emoji.

TEXT
Keep visible text to an absolute minimum: short Chinese labels only. Do not
write paragraphs. Garbled text is acceptable in this pass; layout and hierarchy
are what matter.

NEVER include: a fake iOS status bar, a fake keyboard, emoji, stock photos,
purple or blue gradients, rounded shadow cards, three identical feature cards.

DO NOT draw the cat illustration in detail — leave a clearly marked empty area
where the illustration goes, or draw it as a simple flat silhouette. The real
artwork already exists and will be composited in later.
```

## 四、出图后怎么核

八张回来后只核四件事，不要陷进细节：

1. **层级对不对**——标题、正文、次要文字三档能不能一眼分开
2. **按钮语言是否统一**——主按钮全部实心满宽，次要动作全部是带下划线的文字
3. **选中态是否明确**——选外观和起始气质那两屏，选中和未选中的差别够不够
4. **有没有跑出系统**——出现渐变、厚投影、emoji、假状态栏就打回

**文字乱码不用管**，那是预期内的。
