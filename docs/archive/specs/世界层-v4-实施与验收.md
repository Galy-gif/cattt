# 世界层 v4：动作连续性与池塘玩水

2026-09-10。用户批准《世界层-v4-动作连续性与池塘玩水优化方案》后实施。v3 原文件完整备份在 `outputs/world-v4/baseline/`。

## 已接入

- **体型**：去掉进窝 0.75 缩放；新增动作按约 40pt 的头宽标尺和逐格接触点导出，保持统一显示标尺和支撑原点，不再按每个动作组的外接框高度分别归一。最后按动作组裁掉透明留白，并同步画布尺寸与 footY，猫像素大小及接触坐标不变；74 张 v4 帧的理论 RGBA 解码量从 82.32MiB 降至 36.98MiB（约减少 55%）。
- **树窝**：磨爪后先走到窝下，再蓄力、腾空、抓沿攀入、眨眼／闭眼休息、探身跳下、缓冲并走回。抓沿阶段支撑坐标固定；世界时间跨阶段保留余量。镜头从走到窝下开始就按起落范围取景，减少跳起时追着猫横移。
- **栅栏**：搭爪、踩踏、换爪、收后腿与趴下使用独立 rail 动作，不再共用入窝姿态。使用原横梁，并增加藏在原立柱后方的下横档，去除原先孤立拼接的上横梁。玩花与攀栏分开，下一次空闲时点击栅栏可切换互动。
- **道路**：按路径切线和方向缓冲选择侧走／朝前／背向动作，普通节点不暂停掉头；取消所有地点到达后统一对齐预设朝向的规则，磨爪等接触动作保留必要方向。步态切换保留已行进距离，真正反向出发才播放完整转身；修正 turn 最后重复镜像的帧序列。
- **背景**：保留原树完整轮廓与透明信息，新吊窝单独成层。窝后壁、猫、前沿按局部关系叠放，去除原先逐渐变大的矩形洞口遮罩。新增树候选叶间空隙过多，未采用。原 v3 的唯一镜头坐标、完整底板和地块预取机制继续使用。
- **池塘**：岸边站稳、看水、伸爪、轻拍两次、追看涟漪、收爪甩水、坐下和恢复站姿。触水事件驱动局部椭圆水纹和少量水滴，水面轮廓裁切防止水纹扩到草地；空闲时再次点击池塘可重播。换地点会完成收尾后再行走。

首轮录屏发现新吊窝漏进工程资源清单，App 回退到 v3；已修复并重建，该轮放在 `first-fallback/`，不能用作 v4 验收。第二轮进一步调整池边接触点、保留原树轮廓并清理下横档裁片，旧片段分开保留为中间记录。

最终运行片段：`final.mp4` 覆盖树窝进出、栅栏上下、玩水与再次触发、连续找猫及拖动；`route.mp4` 覆盖从屋前沿石板路到栅栏的行走。`final-*.png` 与 `final-*.json` 为配套截图及运行状态。

最终约 66 秒录制采样峰值 RSS 为 386.2MB，启动后其余采样范围为 273.0–386.2MB；透明裁边前同脚本峰值为 428.5MB。环境／缓存也会影响 RSS，不能把差值全部归因于裁边。最终世界状态为池边空闲，纹理校验无错误；显示时钟回调间隔 P95 为 22.92ms，模拟逻辑平均 0.035ms。高清尚未齐备计数 31 帧包含启动加载，期间有完整底板兜底；该计数不能当作可见空白帧。上述均不是 GPU 帧率或真机性能承诺。

已复查树窝抓沿／休息、栅栏上下、池边伸爪与找猫横移的录屏关键帧；没有将位图姿态切换等同骨骼动画连续性。录制后已恢复模拟器正常自主活动。最终录制脚本会先保留旧视频再开始新录制，并等待末次快照，避免误用旧文件。

自动检查只证明记录中的逻辑与资源条件；正常速度和逐帧画面需单独复查。当前是多张位图关键姿态配合连续位移，尚不是连续骨骼动画。未做 iOS 17 真机或真机 GPU 帧率验证，未发布 App。

## 可复现入口

```sh
swiftc -O assets/tools/package_world_v4.swift -o outputs/world-v4/review/package-v4
outputs/world-v4/review/package-v4
python3 assets/tools/configure_world_v4.py
python3 assets/tools/validate_world_v4.py
python3 ios/generate_project.py
```

构建后另运行资源校验，将实际 `.app` 路径作为 `validate_world_v4.py` 的参数。模拟器录制脚本为 `outputs/world-v4/review/capture.py`，接受 `final`、`route`、`camera` 等场景参数。

主要代码：`WorldInteraction.swift`、`WorldScene.swift`、`WorldView.swift`、`CatAction.swift`、`AppStore.swift`。源图与实际提示词在 `assets/tuanzi/world-v4/`，场景独立配置在 `assets/scenes/courtyard-v4/scene.json`。
