## 0. 三条不能违反的规则（2026-09-08 修订）

1. **猫必须一眼可见**：猫与周围地面色相角距 ≥ 55°，且猫的饱和度明显高于地面（S 差 ≥ 0.2）。
2. **画面必须有三簇色相**：暖 10–35°、绿 80–120°、青 180–200°。发闷的根因是色相挤在窄扇区。
3. **暗部分类型**：平涂背景板 `L<60` 占 8–15%；整幅插画只要求天空区 `L>85` 占 60% 以上。

旧版「地面必须 100–120°」是给平涂背景板写的，套不到整幅插画上，已改为直接量目的。理由和数据见 `docs/决策-2026-09-08.md`。

## 4. 产品口径（来自飞书全景清单，摘要）

- 无打卡、无等级、无喂养压力。不做计数驱动界面。
- 一级导航：陪伴 / 日记 / 我的。「日记」是否正式替换「回忆」仍待确认。
- 聊天：点「聊会儿」直接进唯一的默认专注聊天页，猫话左、人话右，没有新建会话，只有一条连续关系。
- 日记：所有碎片默认允许团子阅读；团子到访三态 = 未读无标记 / 读过只留脚印 / 有评论才显示头像和文字。
- 创建流程：选外观 → 起始气质（四个预设，用行为描述） → 命名 → 初次见面（它先开口）。目前只有橘猫有定稿。
- P0 先验证：创建猫、文字陪伴、性格差异、可控记忆。P1 再补语音、动作、主动消息、日记、灵感卡。

完整口径以 `docs/feishu/猫猫功能与页面全景清单.md` 为准，性格机制看 `猫的个体差异机制.md`。
