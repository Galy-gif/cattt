# 统一提交与活动协议对齐

用户明确要求把截至目前的项目工作全部推到远端。本次统一收录代码、3D 源模型、正式资源、决策与验收证据；本机凭据、构建缓存、原尺寸截图和录屏继续按工作约定留在本地。各轮报告里的“未提交／未推送”描述其当时状态，统一提交后的状态以 Git 记录为准。

推送前复核发现：iOS 正常活动池已经包含歪头、情绪、追尾巴、伸懒腰、小跑、抓树和扑花，后端世界快照却只接受四种基础活动。后端活动枚举补齐至当前正式活动池，避免正常状态上报和动作回执被返回 400；继续拒绝未知活动。回归测试从 `ios/Maomao/Model/YardIntent.swift` 读取正式活动池，检查这些活动均可通过后端协议。

本次为仓库同步与上述协议修正。产品能力和各轮验收范围沿用既有记录；真机、公网部署与更广模型质量仍按原边界另验。
