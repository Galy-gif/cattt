# iOS 原生日期处理优化

用户要求第二批提交推送到 main，并继续针对 iOS 优化。第二批已以 `a70cf99` 推送并核对远端 main。

第三批优化 Swift 原生的日记日期处理：归档日期键改用 `ISO8601FormatStyle`，中文日期标签使用值类型解析与格式策略，让 Foundation 复用内部格式化器，减少院子每秒检查和日记界面的重复构造开销。归档仍使用指定时区，中文标签仍采用公历和中文星期；旧版对非标准日期的解析继续保留。

新增仅 Debug 可用的 `datePerformance:标签` 批量基准入口，采样日期键与标签处理耗时。它是合成基准，不作为 App 帧率、能耗或真实列表打开时间。
