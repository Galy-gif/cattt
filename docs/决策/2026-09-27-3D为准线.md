# 3D 为准线，2D 冻结 · 2026-09-27

用户 2026-09-27：「现在以 3d 为开发准线 2d 不再开发」。

1. **开发准线是 3D。** 院子与团子的下一步开发都在 3D：网页院子（`web/`、`assets/yard-3d/`）与 3D 团子（`assets/tuanzi-3d/`）。iOS 通过已定的 WKWebView 内嵌路线接它（[决策-2026-09-17-iOS同步](2026-09-17-iOS同步.md) 第 5 条、[方案](../方案/iOS-3D世界层与界面同步-方案-2026-09-17.md)）。
2. **迁移已经在进行中，讨论的不是要不要迁。** 第 0 轮真机实测闸门已通过（[实施与验收](../方案/iOS-3D世界层与界面同步-实施与验收-2026-09-20.md)）；第 1 轮结构／竖屏构图的独立预览已经进了 App——`Features/Yard3D/YardWebHost.swift` 加调试面板的「3D 院子」「3D 构图预览」，真机上的缩放、全景与找团子操作用户已确认正常；院子又按半山小院方向扩了一次（[方案](../方案/半山小院扩展与总览收紧-方案-2026-09-26.md)、[最新布局评审](../../outputs/yard-layout-review/验收报告.md)）待用户看图。
3. **首页还是 2D，这是唯一没切的一环。** `RootView → CompanionHomeView → WorldView` 读的仍是 `Model/WorldScene`；3D 只在 DEBUG 入口，所以现在打开 App 看到的院子还是 2D。构图与布局定稿之后，下一步就是把首页换成 `YardWebHost`，并把聊天、信箱、地点轨这些入口接过去。
4. **Swift 2D 世界层冻结。** `ios/Maomao/Model/WorldScene|WorldInteraction|WorldDepth|WorldCamera|WorldMood` 里的世界层运行逻辑与它的逐帧素材（`assets/tuanzi/frames-*`、2D 场景贴图）只修阻断性 bug，不再加功能、不再出新帧、不再重渲。冻的是表现层与素材产线，不是规则。
5. **2D 的待办一并暂停。** [逐帧v5 出图与播放规则](../方案/逐帧v5-出图与播放规则-方案-2026-09-11.md)、[团子自然动作规范](../方案/团子自然动作-规范-2026-09-16.md)、[喝水与水盆衔接方案](../方案/喝水与水盆衔接-方案-2026-09-16.md)、[团子统一与树窝姿势方案](../方案/团子统一与树窝姿势-方案-2026-09-16.md) 里还没做的部分（v8 端点与连续帧、口碗衔接、树窝姿势重出）停在这里；3D 团子的造型与动作走 `assets/tuanzi-3d/`。
6. **退役时点确认为现在，但素材与代码先不删。** 09-17 决策第 2 条写的「退役时点和 2D 素材的删除另行确认」在这里确认时点——从今天起 2D 只有保底职责；删除要等首页真正切到 3D、2D 世界层不再被 App 加载之后再做，那是单独一次动作。
7. **规则类文档继续有效。** 情绪/时段/天气、性格与 Soul、院子与聊天的分工这些**规则**不随冻结（后端与 App 行为在用），迁移时要跟着搬到 3D 那侧，不能丢。
8. **界面层不受影响。** 聊天、日记、我的、创建流程仍是 SwiftUI，`maomao-ui` 技能继续有效；`maomao-assets` 讲的 2D 出图与接入不再按它推进。
