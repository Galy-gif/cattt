# 3D 为准线，2D 冻结 · 2026-09-27

用户 2026-09-27：「现在以 3d 为开发准线 2d 不再开发」。

1. **开发准线是 3D。** 院子与团子的下一步开发都在 3D：网页院子（`web/`、`assets/yard-3d/`）与 3D 团子（`assets/tuanzi-3d/`）。iOS 通过已定的 WKWebView 内嵌路线接它（[决策-2026-09-17-iOS同步](2026-09-17-iOS同步.md) 第 5 条、[方案](../方案/iOS-3D世界层与界面同步-方案-2026-09-17.md)）。
2. **Swift 2D 世界层冻结。** `ios/Maomao/Model/WorldScene|WorldInteraction|WorldDepth|WorldCamera|WorldMood` 里的世界层运行逻辑与它的逐帧素材（`assets/tuanzi/frames-*`、2D 场景贴图）只修阻断性 bug，不再加功能、不再出新帧、不再重渲。冻结的是表现层与素材产线，不是规则。
3. **2D 的待办一并暂停。** [逐帧v5 出图与播放规则](../方案/逐帧v5-出图与播放规则-方案-2026-09-11.md)、[团子自然动作规范](../方案/团子自然动作-规范-2026-09-16.md)、[喝水与水盆衔接方案](../方案/喝水与水盆衔接-方案-2026-09-16.md)、[团子统一与树窝姿势方案](../方案/团子统一与树窝姿势-方案-2026-09-16.md) 里还没做的部分（v8 端点与连续帧、口碗衔接、树窝姿势重出）停在这里；3D 团子的造型与动作走 `assets/tuanzi-3d/`。
4. **退役时点确认为现在，但素材与代码先不删。** 09-17 决策第 2 条写的「退役时点和 2D 素材的删除另行确认」在这里确认时点；删除要等首页真正切到 3D、2D 世界层不再被 App 加载之后再做，那是单独一次动作。
5. **规则类文档继续有效。** 情绪/时段/天气、性格与 Soul、院子与聊天的分工这些**规则**不随冻结（后端与 App 行为在用）；冻结的只是 2D 的画和它的产线。
6. **界面层不受影响。** 聊天、日记、我的、创建流程仍是 SwiftUI，`maomao-ui` 技能继续有效；`maomao-assets` 讲的 2D 出图与接入不再按它推进。
