# 旧原话检索与输入预算 · 2026-11-16

本轮沿用陪伴定位、团子相关托付范围、worker结构化汇报及API唯一出版；不增加联网、外部文档、代码执行或UI能力。

前台与后台按需检索最近30条之外的已许可用户原话，只接受查询及消息ID，归属和本轮上界由宿主绑定。保守排除所有猫回复和日记关联原话；useMemories控制读取，learnMemories不控制读取。动态来源先登记，再交给模型，继续参与现有撤回、版本检查及出版契约。

模型每步执行固定64KiB总量的字节估算预算（56KiB输入、8KiB输出预留，输入估算含1KiB开销），不是供应商精确token计数。只裁剪请求副本中的旧完整对话／工具轮次；worker保留全部用户输入，不裁剪数据库历史或检查点，不新增摘要模型调用。必要内容超限明确失败。

实现、测试证据及边界见[本轮验收](../方案/旧聊天检索与模型输入预算-实施验收-2026-11-16.md)。未提交、未推送、未部署。

## 同轮复核补充

前文“最近30条之外”在本次复核后调整为本轮之前的全部已许可用户原话：输入预算可能移除近期消息，工具必须能查回。归属、来源许可和本轮上界不变。搜索返回命中位置附近摘录；展开支持 Unicode 码点 offset 与 nextOffset，以便完整读取长原话且保持单次返回有界。

## 真实模型复核补充

保持worker思考模式，工具选择改用供应商支持的auto；普通文字不能绕过report交给前台。关闭记忆读取的工具结果明确标记不可用，不能把它解释为用户以前没说过。真实DeepSeek与HTTP/SSE证据见[真实模型验收](../../outputs/personal-agent-live-review/验收报告.md)。
