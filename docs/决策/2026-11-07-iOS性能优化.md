# iOS 性能优化

用户要求优化 iOS 性能。本轮处理两处已量测的重复工作：3D 跟随镜头只在地点变化时发布 `viewedIndex`；逐帧完整性能采样与整段统计报告只在显式 `review`／`debug` 网页模式启用。正式运行仍每秒保存世界恢复快照，真实活动回执继续即时同步。

增加仅 Debug 可用的 `performance:标签` 启动脚本命令，用五秒窗口记录真实 `AppStore.objectWillChange` 通知数，供后续复测。通知数不等于 SwiftUI 绘制次数，也不作为 FPS 或能耗结论。

实现、量测和验收边界见 [本轮报告](../../outputs/ios-performance-review/验收报告.md)。本轮未提交、未推送；真机能耗与帧率尚未测量。

同日补记：用户明确要求将本批提交并推送到 main，然后继续优化。交付状态以 Git 记录为准，后续改动继续在独立 worktree 验证。
