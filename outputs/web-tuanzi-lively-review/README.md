## 造型与材质

生成参数：主躯干宽度 −14.9%、厚度 −19.3%，胯宽 −16.0%，胸宽 −20.5%；头部上提25mm并略前移，显出下颌。耳轴 +34.7%，尾链弧长 +37.5%，尾根半径 +20.7%、尾尖半径 +31.6%。具体量值与定义在 `proportions.json`；它们不是整幅渲染的外接框，也不是猫的体积变化率。没有整猫或逐动作缩放。

保留橙色及原纹样、小豆眼与小嘴。低对比底色纹理、绒面受光与温润眼睛取代旧的重哑光表面；网页四层共用毛根的短绒跟随蒙皮，最外层2.8mm，透明混合减轻细碎砂点。Blender静帧呈现柔软表面，细绒是网页实时材质，不宣称 `.blend` 内含参考图那种离线密集毛发系统。参考图只借材质，不照搬三只叠猫的造型与颜色。

走路略提脚，头部跟随晚一点，耳尖轻摆，胸背约0.8%的局部弹性；四足承重与原七动作接口保留。额头减面中线的小折光用原曲面梯度法线修正，原UV保留。

## 实测

最终文件SHA见 `artifact-hashes.json`；参考和旧版来源见 `baseline.json`。旧版纹样从修改前GLB嵌入JPEG恢复以重渲染，原运行模型留在 `assets/tuanzi-3d/baselines/`。对照并未重造一只替代旧猫。

|检查|结果|
|---|---|
|原始模型|18,878三角面；32骨骼、七段动作、眼睛眨眼形态键；1,158,220字节|
|绒毛额外开销|四层共用身体几何，每层17,998面，另提交71,992面；不增加GLB几何数据|
|连续身体|9,002顶点属于同一连通组件；头颈不是分开的零件|
|循环首尾|idle/walk/turn_step/sit_idle 脚掌与尾尖端点差0|
|坐下／起身尾部最低点|+2.830mm / +2.132mm，未穿地|
|全动作网格最低点|−0.264mm，脚底蒙皮的亚毫米误差|
|坐站四爪端点移动|约0.004mm|
|坐姿抖耳与呼吸|四爪最大漂移0.568mm；尾末节姿势误差0|
|路线支撑脚滑移|直走0.080%、掉头走0.357%、直角走0.432%、曲线0.262%；转身最高0.583%身长，均低于2%|
|切换位移速度|最高0.30倍走速；低于1.5倍|

Blender最终工程逐帧采样见 `lively-after-metrics.json`；Node直接加载最终GLB与生产动作控制器，去掉贴图测试，见 `runtime-tests.json`。`pnpm --dir web build`通过。`repo_check.py`默认只验暂存区，本轮无暂存；本轮文件大小、文档登记另查，不将空暂存区通过冒充全部改动审计。

浏览器1440×900检查了新版模型、柔软短绒与坐下／坐姿／抖耳／行走。停止本轮Blender任务时的数次读数约49–60fps，缩放0.75；未做持续55fps性能验收。高频绒毛在较小显示尺寸下会变成柔软轮廓，不能将局部特写当成院子实际显示效果。未新增喝水、进窝等动作，iOS及院子结构未改。
