# 创建资料保存与恢复

2026-10-24。创建步骤、猫名、气质细调、初见输入和确认档案已接入本机保存。用户授权见[决定](../../docs/决策/2026-10-24-创建资料恢复.md)。真实模型验收等待充值；本轮没有调用模型、部署、提交、推送或真机验收。

## 实现

- `CreationStorage.swift`：版本化原子文件，正式档案与创建草稿独立；稳定ID、原始初见回答、对话行ID和领养日期一并保存；读取校验版本、性格范围和关键状态。
- `AppStore+Creation.swift`：启动/身份切换时先恢复资料，再连接后端；编辑及时保存，步骤/完成先落盘后切页；异步问候和回复可接续；重复发送及完成有阶段限制。失败保留输入，重新读取前不覆盖损坏原件。
- `AppStore+Conditions.swift`：不再在尚未创建时提前落盘领养日期；原全局气质/特征/日期只迁移到原本机空间。
- 创建页面提供读取/保存错误和重试；命名与初见沿用聊天/日记的屏幕坐标口径避让软件键盘。
- 既有远端猫设定请求捕获发起时的客户端和档案ID，避免切换账号后用新账号发送旧资料或显示旧错误。本轮未增加远端档案同步协议。

## 边界

这是本机恢复：没有正式登录、跨设备创建资料恢复、云端称呼/初见来源同步，也没有证明真实模型会在以后对话使用初见称呼。既有远端猫设定更新失败仍由连接状态报告，不把本机确认宣称为云端同步成功。

旧版本未保存过的名字、称呼和步骤无法恢复。旧本机资料保守迁移；开发身份没有本机档案时维持原有院子入口，不从旧全局资料猜测该账号身份。真机及最低iOS17验收仍待补。
