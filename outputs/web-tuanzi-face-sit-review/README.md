## 第二轮：嘴

用户看过第一轮："大致没有什么问题，就是猫猫嘴巴要这种，然后嘴巴和鼻子不要连起来"。去掉人中，嘴改成短粗、两头圆的深棕"ω"，鼻子略缩小并和嘴隔开，见 `口鼻第二版.png`。只动了贴图，网格、骨骼、动作不变；`脸与耳-前后对照.png` 里的嘴是第一版。第一次 2D 小样线太粗、两个兜太窄，读成小胡子，放宽收细后才烘。

生成脚本新增 `--repaint`：位置／法线／遮蔽烘焙缓存在 `renders/bake-cache.npz`（不进仓库），外形没改时只重画纹样，省掉约 3 分钟烘焙。

## 过程里踩到的

- 坐姿第一次试骨盆后倾 34°、脊柱不弓：前爪悬空约 5 cm。前腿站着时已经伸直，肩不能抬，只能抬后背。
- 弓背后前腿刚好绷直：呼吸起伏带着前爪上下浮 5.4 mm，回归检查里"抖耳时支撑爪漂移"从 0.57 涨到 5.5 mm。把肩再压低约 8 mm 后回到 0.71 mm。
- 额头中线两点亮斑：对称减面留下的翻折小三角面（法线朝后），全身 5 处。新增 `fix_folds` 在减面后自动并掉；上一版同一位置也有，只是高光没打到。
- 鼻子第一版三个角是尖的：拿三个半平面取最大值再外扩，得到的还是尖角三角形；改成到三角形边的真实距离再外扩才是圆角。
- Blender 放后台跑会被系统降速到十分之一，`taskpolicy -B -p <pid>` 解除。

## 不满意怎么恢复

`previous-version/` 是改前五个文件的原样备份（哈希与 `outputs/web-tuanzi-balance-review/rollback-hashes.json` 里的恢复版一致）：

```bash
cd outputs/web-tuanzi-face-sit-review/previous-version && cp build_tuanzi.py tuanzi.blend build-manifest.json ../../../assets/tuanzi-3d/ && cp tuanzi_color.png ../../../assets/tuanzi-3d/textures/ && cp tuanzi.glb ../../../web/public/models/
```

也可以只退其中一项（比如只要旧嘴）：改 `build_tuanzi.py` 里对应小节再整套生成，各项互不依赖。
