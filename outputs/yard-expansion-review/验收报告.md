# 小院扩展 · 实施与验收

状态：第一版扩院的历史候选。用户评审后要求扩大池塘／蘑菇屋、整理石路、延长栅栏、移除木牌并解开树屋遮挡；最新实施见 [布局调整报告](../yard-layout-review/验收报告.md)，本目录不代表当前画面。2D首页保留，本批随 `web-desktop` 分支提交并推送。

方案：[半山小院扩展与总览收紧](../../docs/specs/半山小院扩展与总览收紧-2026-09-26.md)，用户确认后实施。

## 这版改了什么

- 真实展开院内空间：蘑菇屋、大树、猫窝与池塘重新拉开距离，中央和前侧增加连续草地，补入穿行、池边绕行与树下停留路线。
- 少量添景：一张木长凳、三块天然山石、一小片低花丛。沿用邻近物件的木、石与花材质，主要物件与团子自身尺寸不变。
- `makeHills()` 前后源码完全一致，远山、远处树林与中景灌木没有缩放；团子 GLB 的 SHA-256 与上一版完全一致。地面仅扩大平缓活动区，近景草调整分布与高度，保持中央视线通畅。
- 原先渲染小路与可行走路网不完全同源；现已统一，避免移动物件后旧装饰路径仍穿过它。木凳与山石补入碰撞边界。
- 总览按主要物件及实际院界分别投影，结合真实控件矩形取景，排除院外山景；全景俯角候选44°，固定48°视场角。最远距离随设备计算，日常距离与团子画面大小保持。
- 快照增加 `open-yard-v2` 布局版本。同版本保留镜头与坐标；无版本或旧版本回到同名地点的安全落点，避免旧坐标落入移位后的物件中。

## 扩展量测

来源：[layout-measurements.json](layout-measurements.json)。

| 指标 | 扩展前 | 扩展后 |
|---|---:|---:|
| 路网中可达节点 | 22 | 31 |
| 路段 | 21 | 34 |
| 不重复路段总长 | 10.765m | 31.589m |
| 可达路网的凸包面积 | 9.810m² | 26.978m² |
| 25mm间隔采样的最小净距 | 0.00607m | 0.00061m |
| 真机总览院内合并投影框 | 322.75 × 190.64pt | 418.27 × 289.18pt |
| 真机日常团子高度 | 约15.8%屏高 | 约15.8%屏高 |

净距已扣除团子0.22m足迹半径与0.04m安全余量；数值小不表示猫贴着实体。新增院界多边形面积52.919m²，旧版没有对应院界定义，因此不声称“院子面积翻了几倍”。路网凸包也不等于全部自由漫游面积，团子仍沿路径行走。

新版真机总览距离约25.884m，比旧版22.714m略远，但覆盖的是扩展后的整个院子；院内投影框更大，画面高度由约20%增至约30%。此处使用合并框作前后尺寸记录，实际取景使用各物件和院界；合并框上方空角不作为遮挡判定。可用像素变多不等于用户已认可观感。

## 真机复测

测试用×1.5、MSAA关闭、60fps目标、完整辉光、2048阴影、完整草量开关与四层绒毛。模拟器关闭后开始测试。

本版屋前60.137秒中位58.8／最慢1% 37fps、最低自适应倍率0.90；夜雨全景60.161秒55.6／38.5fps、最低0.75。出现性能回退，不判通过。后续按新布局合并木凳／花丛／栅栏等静态零件，重新采样；本版散步长测因用户提出新布局要求而中止，不能记为通过。一次屋前采样曾被后台暂停59秒打断，已另存本地，不混入有效样本。

## 能力边界

- 本轮是独立预览。首页行为迁移与业务点击仍未开始；观感由用户评审。
- 少量添景不新增聊天、坐凳或出院上山动作。散步路线真实可达，院外背景仍不是可达地图。
- iOS模拟器仍有此前记录的矩形阴影块，真机无该现象；正式评审图全部使用真机。
- 本轮自动化不能代替真实双指手感确认；旧版用户确认不自动转移到新版。真机录屏接口此前已确认不支持，未将旧录像或模拟器录像当作新真机逐帧证据。
- 方案提到“屋前看向池塘”的方向仍通过横向浏览与地点取景实现；没有新增旋转手势。

## 复现入口

```bash
python3 assets/yard-3d/make_paths.py
blender -b --factory-startup -P assets/yard-3d/build_yard.py -- --no-render
pnpm --dir web typecheck
pnpm --dir web test:app
pnpm --dir web build:ios
python3 ios/generate_project.py
# 安装Debug构建后，按设备参数采样
python3 tools/capture_yard_composition.py --device <模拟器ID> --label iphone17pro-simulator --ui YES --output outputs/yard-expansion-review
python3 tools/check_yard_expansion.py --device <真机ID> --bundle <实测bundle>
python3 tools/package_yard_expansion.py
```

新增调试参数 `-yardCompositionView comparison` 固定第一版机位，用于真实同机位对照；交互会退出固定对照。`-yardCompositionStroll YES` 以正常步速走一圈，人工操作入口在头像菜单。截图脚本显式关闭散步、恢复、演示和定时采样，避免参数残留。
